הדירוגים של /salary-tables הם על חיפושים לפי תפקיד, כמו "מהנדס מכונות שכר", "מנהל פרויקטים שכר" ו"קצין ציות שכר", כשליש מהם במקום 1. כל תפקיד מופיע בעמוד הזה כטקסט ב-HTML, ו-Google יכול לקשר אותו לחיפוש על אותו תפקיד.

המצב היום: אינדוקס, canonical ופיצול הדירוג

שני העמודים פתוחים לאינדוקס ושניהם באינדקס

  • שתי הכתובות מחזירות 200. ב-/salary-tables מוגדר index,follow. ב-/salary_tables אין תגית robots, כך שגם היא פתוחה לאינדוקס.
  • שתיהן קיבלו הופעות וקליקים מ-Google באוגוסט 2026, ושתיהן מדורגות בתוצאות החיפוש בישראל בספטמבר 2026.
  • שתיהן מופיעות ב-sitemap.xml.

canonical: כל עמוד מצביע על עצמו

ב-/salary-tables ה-canonical הוא https://www.manpower.co.il/salary-tables, וב-/salary_tables הוא https://www.manpower.co.il/salary_tables. אף אחד מהעמודים לא מצביע על השני, ולכן Google מתייחס אליהם כשני עמודים נפרדים עם אותו נושא.

Google מחלק את החיפושים בין שני העמודים

  • החיפוש הכללי "טבלאות שכר" (כ-1,900 חיפושים בחודש) מוביל היום ל-/salary_tables, במקום 4.
  • החיפושים לפי תפקיד מובילים ל-/salary-tables.
  • על חלק מהחיפושים שני העמודים מתחרים ישירות: "טבלאות שכר ביוטק" (שניהם במקום 2) ו"טבלת דרגות שכר במגזר הציבורי" (מקום 7 ומקום 20).

ב-/salary_tables רוב התפקידים לא נמצאים בקוד העמוד

בכל טבלה מוצגים 3 תפקידים, והשאר מתווספים לדף רק אחרי לחיצה על "הצג תפקידים נוספים". ב-HTML של העמוד יש 36 שורות תפקיד מתוך 275, ושאר התפקידים נמצאים רק בתוך נתוני ה-JavaScript של העמוד. Google לא לוחץ על כפתורים ולא קורא נתוני סקריפט כתוכן העמוד, ולכן הוא לא רואה את רוב התפקידים. זו הסיבה שהעברה של העמוד כמו שהוא לכתובת /salary-tables תפגע בדירוגים לפי תפקיד.

הנתונים ב-/salary_tables מעודכנים יותר

אחרי פתיחת כל הכפתורים, /salary_tables מציג 275 שורות תפקיד מול 258 ב-/salary-tables. בעשרות תפקידים שמופיעים בשני העמודים טווחי השכר עודכנו, ובעמוד החדש יש כ-20 תפקידים שלא היו בישן. רוב התפקידים שנראים כאילו הוסרו קיימים בעמוד החדש בשם מעט שונה (למשל "מלגזן/ית" ו"מלגזן"). ארבעה תפקידים קיימים רק בעמוד הישן: HRBP, HR Specialist, יועץ משפטי, ו"יועמ”ש/ית או מנהל/ת תחום / מזכיר/ת חברה ראשי/ת".

כתובות נוספות שמציגות את אותו עמוד

  • /Salary-Tables ו-/SALARY-TABLES מחזירות 200 עם canonical לכתובת עצמה, כלומר עותק נוסף של העמוד בכל וריאציה של אותיות גדולות.
  • /Salary_Tables מחזירה שגיאת שרת 500.

קישורים פנימיים

כל 1,275 העמודים הפעילים שבמפת האתר מקשרים ל-/salary_tables דרך הקישור "טבלאות שכר" בתפריט הראשי וב-footer. הכתובת /salary-tables, שמביאה את רוב התנועה, מקבלת קישור פנימי מעמוד אחד בלבד מתוכם.

הוראות יישום לצוות הפיתוח
  1. להעביר את העמוד החדש לכתובת /salary-tables. הכתובת /salary-tables מציגה את הרכיב, הנתונים והעיצוב של /salary_tables: נתוני 2026, בלוק המאמרים הקשורים, בלוק המשרות וסכמת BreadcrumbList.
  2. כל התפקידים בקוד העמוד בטעינה. כל שורות התפקיד צריכות להופיע ב-HTML שהשרת מחזיר. הכפתור "הצג תפקידים נוספים" רק מציג או מסתיר שורות שכבר נמצאות בדף, באמצעות CSS או מאפיין hidden. הוא לא טוען נתונים ולא מוסיף רכיבים לדף.
  3. כותרות. ה-title וה-meta description של /salary_tables (2026) עוברים ל-/salary-tables. הכותרת הראשית "טבלאות שכר מעודכנות 2026 – לפי תפקיד, ענף ושנות ניסיון" מוגדרת כ-<h1>. כרגע אין H1 באף אחד משני העמודים.
  4. canonical קבוע. ב-/salary-tables ה-canonical הוא תמיד https://www.manpower.co.il/salary-tables, כתובת מלאה ובאותיות קטנות, ולא נבנה מהכתובת שהמבקר הקליד.
  5. הפניית 301. /salary_tables מופנית ל-/salary-tables בהפניה אחת, עם שמירה על פרמטרים (utm וכדומה). ב-Next.js: 
    // next.config.js
async redirects() {
  return [
    { source: '/salary_tables', destination: '/salary-tables', statusCode: 301 },
  ];
}
  6. וריאציות אותיות גדולות. כל וריאציה של הנתיב באותיות גדולות (/Salary-Tables, /SALARY-TABLES, /Salary_Tables) מופנית ב-301 ישירות ל-/salary-tables, בהפניה אחת. זה גם פותר את שגיאת ה-500 ב-/Salary_Tables. לדוגמה, ב-middleware: 
    // middleware.js
import { NextResponse } from 'next/server';
export function middleware(req) {
  const p = req.nextUrl.pathname;
  if (/^\/salary[-_]tables\/?$/i.test(p) && p !== '/salary-tables') {
    const url = req.nextUrl.clone();
    url.pathname = '/salary-tables';
    return NextResponse.redirect(url, 301);
  }
}
  7. קישורים פנימיים. כל הקישורים ל-/salary_tables מוחלפים בקישור ישיר ל-/salary-tables: הקישור "טבלאות שכר" בתפריט הראשי והקישור "טבלאות שכר" ב-footer (שניהם מופיעים בכל עמודי האתר). שני הקישורים מגיעים מפריטי תפריט במערכת ניהול התוכן: פריט 34940 בתפריט הראשי ופריט 19974 בתפריט ה-footer, ולכן את הכתובת מחליפים שם, בתפריט המובייל אם הוא נבנה כרכיב נפרד, ושני הקישורים בגוף המאמר איך לקרוא נכון טבלת שכר ולהשוות בין הצעות.
  8. ניקוי מטמון. אחרי ההעלאה מנקים את המטמון של Cloudflare עבור /salary-tables ו-/salary_tables, כדי שההפניה והעמוד החדש יוגשו מיד.
  9. מפת האתר. https://www.manpower.co.il/salary_tables יוצאת מ-sitemap.xml. /salary-tables נשארת.
  10. תוכן הטבלאות.
    • ארבעה תפקידים נמצאים רק בעמוד הישן: HRBP ו-HR Specialist בטבלת משאבי אנוש, ויועץ משפטי ו"יועמ”ש/ית או מנהל/ת תחום / מזכיר/ת חברה ראשי/ת" בטבלה המשפטית. אם הם עדיין רלוונטיים, מוסיפים אותם לעמוד המאוחד. בעמוד הישן הטווח של יועץ משפטי כתוב הפוך ("45,000 -40,000 ₪"), ולכן מעבירים אותו כ-"40,000-45,000 ₪".
    • בטבלת משאבי אנוש בעמוד החדש מופיעה שורת "עו”ד מסחרי" עם טווח הפוך ("35,000 -25,000 ₪"). השורה הנכונה כבר קיימת בטבלה המשפטית, ולכן מוחקים את השורה מטבלת משאבי אנוש.
    • בטבלה המשפטית בעמוד החדש, הטווח של "עו”ד מזכירות חברה / מזכירות בנק" כתוב "35,000 -25,000 ₪" ומתקנים אותו ל-"25,000-35,000 ₪".
    אחרי השינויים האלה בעמוד יהיו 274 שורות תפקיד, ועוד שורה לכל תפקיד שמוחזר מהעמוד הישן (עד 278).
