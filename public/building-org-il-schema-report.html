2. Organization - תיקון סכמה כפולה בעמוד הבית (1 עמוד)

בעיה: יש שתי סכמות Organization בעמוד הבית עם אותו @id - Yoast מייצר Organization חלקי (ללא טלפון, כתובת, רשתות חברתיות), ובנוסף קיים EducationalOrganization standalone מלא. הכפילות עלולה לבלבל את Google.

יש להסיר את ה-EducationalOrganization הנפרד ולעדכן את סכמת Yoast Organization בהגדרות Yoast SEO → Search Appearance → Organization:

פתרון מומלץ: עדכון הגדרות Yoast SEO כדי שה-Organization schema של Yoast יהיה מלא, והסרת הסכמה הנפרדת. כך Google רואה סכמה אחת ומלאה.

שדות להוסיף ב-Yoast SEO → Search Appearance → Organization

3. Event - סכמת אירועים (53 עמודים)

בעיה: כל 53 עמודי האירועים מוגדרים כ-WebPage בלבד. אין סכמת Event שמאפשרת ל-Google להציג תאריכים, מיקום ופרטי אירוע בתוצאות החיפוש.

תבנית: articles/event/* (Elementor template)

4. Course - סכמת קורסים (15 עמודים)

בעיה: כל 15 עמודי הקורסים מסומנים כ-Article במקום Course. Google לא מזהה אותם כקורסים ולא מציג Rich Results של קורסים בתוצאות חיפוש.
9 מתוך 15 עמודי קורסים כבר כוללים FAQPage schema (תקין). יש להוסיף Course schema בנוסף ל-FAQ הקיים.
