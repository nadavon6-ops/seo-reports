GeckoCheck Setup Profiles

One setup profile per client for GeckoCheck staff: brand spellings, categories, products, the core search terms per category, a 50-query core set plus a full set, competitors with verified domains, and the checks to run after the next report.

How to use

  • Send each profile to GeckoCheck support. Our account role is User, so GeckoCheck staff make the setup. Each page opens with the list of changes, and the CSV files at its foot are ready for a bulk import.
  • Chery and Leumit are live in GeckoCheck. Their existing queries keep their exact wording, so the August 2026 history stays comparable. The other eight are new brands.
  • The core set is 50 queries per brand, the size this account already runs for Leumit. The full set is for a larger plan.
  • The last column lists the decisions each client needs from you before the profile is sent.
