Change · Add · Fix

The optimization plan

Each item below is specific, tied to a real page, and actionable on the current site. Ordered by impact-to-effort.

High impact

1. Add meta descriptions to every inner page

What we found

Only the homepage has a meta description. All property, weddings, amenities, activities, location and FAQ pages have none — Google is auto-writing the snippet.

Why it matters

The snippet is your free ad in search results. A written, benefit-led description lifts click-through on the rankings you already hold.

How to fix · Easy · ~1 day

In Yoast, write a unique 140–160 character meta description for each page (and each property), leading with the offer and location, e.g. "Private 2-bedroom oceanfront villa in Kihei, Maui — heated pool, daily housekeeping, steps from the beach. Book direct with Makoa Resorts."

High impact

2. Resolve duplicate property URLs (keyword cannibalization)

What we found

Each property exists at two live, indexable URLs — a marketing page (e.g. /villas-by-the-cove/) and a listing page (/accommodation/villas-by-the-cove-estate/). Both return 200.

Why it matters

Two pages on the same topic split ranking signals and compete with each other. The data shows this directly — the homepage and the property page fight for "villas by the cove" instead of one page winning decisively.

How to fix · Medium · dev task

Pick one canonical URL per property (the /accommodation/ listing pages already rank best), then 301-redirect the duplicate to it and update internal links. This consolidates authority onto a single strong page each.

High impact

3. Add lodging & per-property structured data (rich results + AI)

What we found

The site only outputs a generic Organization schema with a logo — no address, phone, geo-coordinates or social profiles, and no lodging/property/offer/review markup anywhere.

Why it matters

Resort, per-property and Review schema are how Google and AI engines understand pricing, amenities, ratings and location — and how you earn star ratings, "from $X / night", and AI-answer citations.

How to add · Medium · high return

① Upgrade the homepage to Resort / LodgingBusiness with full address (2121 Ili'ili Rd, Kihei, HI 96753), phone, geo-coordinates, priceRange and sameAs links to your Google Business Profile & social pages. ② Add Accommodation / Product + Offer markup to each property (beds, occupancy, amenities, price). ③ Add AggregateRating / Review using the guest testimonials already on the site.

Medium impact

4. Add FAQ schema to the FAQ page

What we found

You have a full FAQ page, but it carries no FAQPage structured data.

Why it matters

FAQ markup helps your questions surface in AI Overviews and "People Also Ask" — high visibility for booking questions (cancellation, check-in, pets, minimum stay).

How to add · Easy

Wrap each Q&A in FAQPage JSON-LD (Yoast/Rank Math FAQ blocks do this automatically). Also reuse the most common questions as FAQ blocks on the property and weddings pages.

Medium impact

5. Fix heading structure on property pages

What we found

Property pages use multiple <h1> tags, with section labels like "Amenities" also marked as H1.

Why it matters

One clear H1 (the property name + Maui) tells Google the page's main topic; sections should step down to H2/H3. A muddy hierarchy weakens topical relevance.

How to fix · Medium · template edit

In the property template, set a single H1 = "{Property Name} — Luxury Villa in Kihei, Maui" and demote section headings (Amenities, Location, Reviews) to H2.

Medium impact

6. Improve server response time

What we found

Time-to-first-byte is ~2.1s and full HTML load ~2.4s — the server is slow to respond before anything even renders.

Why it matters

Core Web Vitals are a ranking factor and slow load hurts bookings on mobile. Sub-0.8s TTFB is the target.

How to fix · Medium · hosting

Enable full-page caching (e.g. WP Rocket / server cache), a CDN for images, and confirm the host has adequate resources. Images are already WebP — good — so the focus is server + caching, not the media.

Quick win

7. Strengthen on-page targeting for striking-distance keywords

What we found

High-value terms ("villa maui", "maui villas", "luxury vacation rentals in maui") rank on page 2 mostly via the homepage, with no single page fully optimized for them.

Why it matters

A focused page beats a general one. Small on-page edits to existing pages can push these onto page 1.

How to do it · Easy · ongoing

Optimize the existing Accommodations page as the hub for "Maui villas / vacation rentals", and the Location page for Kihei/Wailea geo-intent: work the target phrase into the H1, intro paragraph, image alt text and internal anchor links from the homepage. Add a short, genuine "About Kihei / Wailea" section to the Location page to deepen local relevance.

Quick win

8. Tighten internal linking between pages

What we found

Property and service pages exist but aren't strongly cross-linked with descriptive anchor text.

Why it matters

Internal links pass authority and tell Google which page owns which topic — directly helps the consolidation in items 2 & 7.

How to do it · Easy

From the Accommodations hub, link to each property using its target keyword as anchor ("Oceanfront villa in Kihei"). Cross-link Weddings ⇄ Events ⇄ Wellness, and link Amenities/Activities back to Accommodations.
