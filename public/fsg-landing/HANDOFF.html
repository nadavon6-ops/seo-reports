I · Contexto

Una boutique jurídica.

FSG es la práctica personal de Fernanda. No es un estudio corporativo: es una asesoría boutique de derecho inmobiliario con estándar notarial. Pocos clientes, atención meticulosa, trato personal.

La marca dice

  • Seriedad — tipografía sobria, bloques sólidos, nada decorativo.
  • Personal — primera persona singular; "yo" cuando habla Fernanda.
  • Estándar notarial — precisión, plazos, documentación escrita.
  • Discreción — nunca superlativos, nunca emoji, nunca "#1".

La marca no dice

  • No es una plataforma masiva.
  • No es un marketplace ni un servicio genérico.
  • No es un estudio de litigios ni derecho de familia.
  • No es corporativo ni distante.

V · Stack sugerido

Cómo montarlo.

El diseño es agnóstico de framework. Recomiendo Next.js 15 (App Router) por fit con Vercel, TypeScript out-of-the-box, y SEO server-side. Pero cualquier opción moderna funciona.

Opción A · Next.js (recomendado)

  • Next 15 + App Router en TypeScript. Obligatorio.
  • app/layout.tsx importa colors_and_type.css como globals.css.
  • Fuentes Nexa en public/fonts/; declaradas con next/font/local.
  • Cada .jsx del kit → .tsx en components/. Copiar JSX verbatim, tipar props.
  • Rutas: / · /servicios/[slug] · /sobre-mi · /contacto.
  • Form de contacto → server action + Resend API.
  • next/image para retratos con priority en el hero.

Opción B · Vite + React (sólo si Next no es opción)

  • Más liviano si no necesitas SSR.
  • react-router para rutas.
  • Deploy como static site en Vercel.
  • Menos SEO-friendly que Next salvo pre-rendering — no recomendado para este caso (una abogada necesita aparecer en búsquedas).
Replicación, no reinterpretación

Los JSX son la fuente de verdad. Los screenshots son el contrato visual.

Si ves algo en el JSX que no está en el screenshot (o viceversa), gana el screenshot. Si algo te parece "raro", preguntá antes de cambiarlo. El diseño ya pasó por iteraciones y validaciones — no necesita tu toque creativo, necesita tu rigor de ingeniería.

Marcá cualquier duda con // TODO(design): <pregunta> en el código. No resuelvas solo.

VI · Setup

Clonar, instalar, deployar.

1. Inicializar Next.js

# crear el proyecto
npx create-next-app@latest fsg-web --typescript --app --tailwind=false --eslint

# copiar assets del handoff
cp -r ./fsg-handoff/fonts ./fsg-web/public/
cp -r ./fsg-handoff/assets ./fsg-web/public/
cp ./fsg-handoff/colors_and_type.css ./fsg-web/app/globals.css

# componentes
mkdir ./fsg-web/components
cp ./fsg-handoff/ui_kits/website/*.jsx ./fsg-web/components/

2. Convertir JSX → TSX

Cada componente necesita: renombrar a .tsx, agregar 'use client' si tiene estado/handlers, tipar props, y reemplazar imports globales por imports ES.

3. Rutas de páginas

# App Router
app/
├── layout.tsx              # Header + Footer + globals
├── page.tsx                # Hero + Services + Process + About preview
├── servicios/
│   └── [slug]/page.tsx     # ServiceDetail dinámico
├── sobre-mi/page.tsx
└── contacto/page.tsx

4. Deploy a Vercel

# push a GitHub
git init
git remote add origin git@github.com:<owner>/fsg-web.git
git add . && git commit -m "feat: initial handoff from design"
git push -u origin main

# conectar en vercel.com/new — auto-detecta Next.js
# dominio recomendado: fsg.cl o fernandasepulveda.cl

VIII · No-goes

Reglas sin excepción.

Prohibido

  • Emoji en UI, correos, social.
  • Superlativos ("el mejor", "#1", "líder").
  • Colores fuera de la paleta.
  • Degradados, glows, sombras dulces.
  • Títulos en Title Case (español = sentence case).
  • "Tú" informal. Siempre usted o voz neutra.
  • Dorado como fondo dominante.

Siempre

  • Frases cortas, oraciones completas.
  • Cifras con formato chileno: UF 1.250 · CLP 45.000.000.
  • Línea dorada de 1px para separar secciones.
  • Aire generoso. Boutique = espacio.
  • Primera persona singular cuando habla Fernanda.
  • Bloques sólidos de color, no transparencias.
  • La banda dorada vertical es parte inseparable del logo.
