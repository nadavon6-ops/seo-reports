1

סכמת הסניף דולפת לשני עמודי אזור, ואותה ישות מוצהרת בשתי כתובות

לתיקון

השיטה החדשה מזהה את עמוד הסניף לפי מזהה, אבל היא פועלת גם בעמודי האזור, שהם עמודי רשימה ולא עמודי סניף. בפועל, כל אחד משני עמודי האזור מציג את הבלוק של הסניף הראשון ברשימה שלו:

עמוד האזורהבלוק שמוצג בוהמזהה שמוצהר
/branch_area/מרכז/סניף כפר סבא, טלפון 03-5496311.../branch/סניף-כפר-סבא/#branch
/branch_area/צפון/סניף חדרה, טלפון 04-6324622.../branch/סניף-חדרה/#branch

שתי בעיות נובעות מכך. הראשונה, אותו מזהה ישות מוצהר עכשיו בשתי כתובות שונות, כך שגוגל מקבל שתי כתובות שמתחזות לאותו סניף וצריך לבחור ביניהן. השנייה, הטלפון והכתובת שבבלוק אינם מופיעים כלל בתוכן הגלוי של עמוד האזור, וגוגל דורש שהסימון ישקף תוכן שהמשתמש רואה בעמוד.

מה עושים: להתנות את הפלט כך שיופיע רק בעמוד סניף בודד, ולא בעמודי ארכיון, רשימה או אזור. בקוד שמזריק את הבלוק, לעטוף את ההדפסה בתנאי:
PHP, תנאי עוטף
if ( is_singular( 'branch' ) ) {
    // כאן ההדפסה של בלוק ה-LocalBusiness
}
לאחר התיקון כדאי לוודא בשני עמודי האזור שהבלוק אינו מופיע בהם יותר, ובעמודי הסניפים עצמם שהוא עדיין מופיע.
2

הגדרות ייצוג הארגון ב-Yoast, שלב א של סעיף 1

לביצוע

קטע ה-PHP שמוסיף לארגון כתובת ודרכי התקשרות פועל. ההגדרות בממשק Yoast עדיין לא עודכנו, ולכן שלוש הצהרות על הארגון נשארות שגויות:

שם הארגון שמוצהר כרגע הוא שם האתר מההתקנה, כולל הסלוגן. זהו השם שגוגל קורא כשהוא מזהה את החברה כישות, ולכן הוא שעשוי להופיע בתוצאות ובפאנל הידע.

מה עושים: בממשק Yoast, במסך Settings → Site representation: להזין שם ארגון Manpower Care, שם חלופי מנפאואר קר, ולהעלות קובץ לוגו שגובהו ורוחבו 112 פיקסלים לפחות. הלוגו הנוכחי נמוך מדי בגובהו.
