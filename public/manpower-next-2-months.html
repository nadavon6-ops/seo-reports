תבנית (להתאים לכל עמוד):
{ "@context": "https://schema.org", "@type": "Service", "@id": "[PAGE_URL]#service", "name": "[SERVICE_NAME_HE]", "serviceType": "[SERVICE_TYPE_HE]", "provider": { "@id": "https://www.manpower.co.il/#organization" }, "areaServed": { "@type": "Country", "name": "Israel" }, "audience": { "@type": "Audience", "audienceType": "[TARGET_AUDIENCE_HE]" }, "category": "Human Resources", "description": "[SERVICE_DESCRIPTION_HE]", "url": "[PAGE_URL]" }
הבדל בין name ל-serviceType: name = שם השירות הספציפי (למשל "שירותי OnSite של מנפאואר"), serviceType = קטגוריית השירות (למשל "ניהול כוח אדם באתר הלקוח"). audience = קהל היעד (למשל "מעסיקים בישראל").

3 ביקורת ותיקון Article/BlogPosting Schema במאמרי הבלוג
היכן כל המאמרים ב-/article/*
למה כיסוי חלקי: חלק מהמאמרים מכילים Article schema וחלקם לא; חוסר עקביות פוגע ב-Rich Results
אחראי פיתוח
מאמץ M
מצב נוכחי (אומת 2026-02-09): העמוד /article/חיפוש-עבודה מכיל Article + FAQPage schema תקינים. אך לא כל המאמרים מכילים schema זהה. נדרשת ביקורת מלאה של כל ~62 המאמרים.
פעולה:
  • לבצע סריקה אוטומטית של כל עמודי /article/* לאיתור מאמרים ללא Article schema
  • ליישם Article/BlogPosting schema אחיד בקומפוננטת מאמר ב-Next.js
  • לכלול: headline, author, datePublished, dateModified, image, publisher, mainEntityOfPage
