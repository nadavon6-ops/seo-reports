תבנית (להתאים לכל עמוד):
{ "@context": "https://schema.org", "@type": "Service", "@id": "[PAGE_URL]#service", "name": "[SERVICE_NAME_HE]", "serviceType": "[SERVICE_TYPE_HE]", "provider": { "@id": "https://www.manpower.co.il/#organization" }, "areaServed": { "@type": "Country", "name": "Israel" }, "audience": { "@type": "Audience", "audienceType": "[TARGET_AUDIENCE_HE]" }, "category": "Human Resources", "description": "[SERVICE_DESCRIPTION_HE]", "url": "[PAGE_URL]" }
הבדל בין name ל-serviceType: name = שם השירות הספציפי (למשל "שירותי OnSite של מנפאואר"), serviceType = קטגוריית השירות (למשל "ניהול כוח אדם באתר הלקוח"). audience = קהל היעד (למשל "מעסיקים בישראל").
