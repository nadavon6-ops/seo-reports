🔴 סכמות חסרות - חובה ליישם

JobPosting Schema קריטי #1
אימות: נסרקו 6 עמודים כולל 3 משרות ספציפיות. לא נמצא JobPosting Schema באף מקום.
השפעה: 1,067+ משרות פעילות ללא Structured Data = לא מופיע ב-Google for Jobs
עמודי יעד: כל עמודי המשרות הבודדות
ארכיטקטורה: SPA (Next.js) - משרות נטענות דינמית, אין עמודי משרה ייעודיים

JSON-LD מומלץ (תקף לפי schema.org):

{
  "@context": "https://schema.org",
  "@type": "JobPosting",
  "title": "[כותרת המשרה]",
  "description": "[תיאור מלא של המשרה, דרישות, תנאים]",
  "identifier": {
    "@type": "PropertyValue",
    "name": "Manpower Israel",
    "value": "[מזהה משרה ייחודי]"
  },
  "datePosted": "2026-01-15",
  "validThrough": "2026-03-15T23:59:59+02:00",
  "employmentType": "FULL_TIME",
  "hiringOrganization": {
    "@type": "Organization",
    "name": "מנפאואר ישראל",
    "sameAs": "https://www.manpower.co.il",
    "logo": "https://www.manpower.co.il/_next/static/media/logo-manpower-white.b713aa15.svg"
  },
  "jobLocation": {
    "@type": "Place",
    "address": {
      "@type": "PostalAddress",
      "addressLocality": "[עיר]",
      "addressCountry": "IL"
    }
  }
}
שדות חובה לפי Google:
  • title - כותרת המשרה
  • description - תיאור (HTML מותר)
  • datePosted - תאריך פרסום (ISO 8601)
  • hiringOrganization - הארגון המגייס
  • jobLocation - מיקום המשרה

שדות מומלצים: validThrough, employmentType, baseSalary, identifier

Article Schema גבוה #2
תיקון חשוב: בניתוח המקורי נטען ש-Article Schema "קיים אך לא שלם".
המציאות: Article Schema לא קיים כלל בעמודי /article/.
מה שנמצא: רק JavaScript data structure פנימי (לא Schema.org markup)
עמודי יעד: כל עמודי /article/[slug] (~20+ כתבות)
דוגמה: /article/קורות-חיים, /article/חיפוש-עבודה

JSON-LD מומלץ (תקף לפי schema.org):

{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "[כותרת הכתבה - עד 110 תווים]",
  "description": "[תיאור קצר / meta description]",
  "image": ["[URL תמונה ראשית]"],
  "datePublished": "2025-06-15T08:00:00+03:00",
  "dateModified": "2026-01-10T14:30:00+03:00",
  "author": {
    "@type": "Organization",
    "name": "מנפאואר ישראל",
    "url": "https://www.manpower.co.il"
  },
  "publisher": {
    "@type": "Organization",
    "name": "מנפאואר ישראל",
    "logo": {
      "@type": "ImageObject",
      "url": "https://www.manpower.co.il/_next/static/media/logo-manpower-white.b713aa15.svg"
    }
  },
  "mainEntityOfPage": {
    "@type": "WebPage",
    "@id": "[URL מלא של הכתבה]"
  },
  "inLanguage": "he-IL"
}
שדות חובה לפי Google:
  • headline - כותרת (חובה)
  • image - תמונה (חובה)
  • datePublished - תאריך פרסום (חובה)
  • author - מחבר (חובה)

שדות מומלצים: dateModified, publisher, mainEntityOfPage

🔧 באג שנמצא - דורש תיקון

BreadcrumbList Schema בינוני
סטטוס: קיים בכל העמודים אבל יש באג JavaScript
מיקום הבאג: עמודי /article/ ו-/insight-lobby

הבאג שנמצא:

{
  "@type": "BreadcrumbList",
  "itemListElement": [
    {
      "@type": "ListItem",
      "position": 1,
      "name": "בית"
      // חסר: "item": "https://www.manpower.co.il/"
    },
    {
      "@type": "ListItem",
      "position": 2,
      "name": "לובי כתבות",
      "item": "undefined/insight-lobby"  // באג! "undefined" במקום domain
    }
  ]
}

תיקון נדרש:

{
  "@type": "BreadcrumbList",
  "itemListElement": [
    {
      "@type": "ListItem",
      "position": 1,
      "name": "בית",
      "item": "https://www.manpower.co.il/"  // הוסף URL מלא
    },
    {
      "@type": "ListItem",
      "position": 2,
      "name": "לובי כתבות",
      "item": "https://www.manpower.co.il/insight-lobby"  // תקן ל-URL מלא
    },
    {
      "@type": "ListItem",
      "position": 3,
      "name": "שם הכתבה"  // פריט אחרון ללא item - נכון!
    }
  ]
}
סיבת הבאג: כנראה משתנה baseUrl לא מוגדר ב-Next.js בזמן build/render
פתרון: וידוא ש-process.env.NEXT_PUBLIC_BASE_URL מוגדר או שימוש ב-hardcoded domain

VideoObject Schema בינוני
מדוע לא אומת:
• לא נמצאו סרטונים מוטמעים בעמודים שנסרקו
• לא ניתן לאמת אם קיימים סרטונים בעמודים אחרים
• הדוח המקורי מזכיר Video Sitemap

מה לבדוק ידנית:

  1. בדוק אם קיים /video-sitemap.xml
  2. חפש עמודים עם YouTube/Vimeo מוטמע
  3. אם קיימים סרטונים - בדוק אם יש להם VideoObject Schema
