🔶 פריטים שנותרו לביצוע

JobPosting Schema 🔴 קריטי
עמודי יעד: כל עמודי פרטי משרה בודדת
דוגמה: https://www.manpower.co.il/job/[job-id]
מדוע נדרש:
• לא נמצא JobPosting Schema באף מקום באתר
• עמוד החיפוש (/search) מציג משרות דינמית ללא סכמת Job
• משרות נטענות ב-JavaScript - אין Structured Data
• Google for Jobs דורש JobPosting Schema להצגה בתוצאות

קוד JSON-LD מומלץ:

{
  "@context": "https://schema.org",
  "@type": "JobPosting",
  "title": "[כותרת המשרה] - [מיקום]",
  "description": "[תיאור מפורט של המשרה]",
  "identifier": {
    "@type": "PropertyValue",
    "name": "Manpower Israel",
    "value": "[JOB-ID]"
  },
  "datePosted": "[YYYY-MM-DD]",
  "validThrough": "[YYYY-MM-DDTHH:MM]",
  "employmentType": ["FULL_TIME"],
  "hiringOrganization": {
    "@type": "Organization",
    "name": "מנפאואר ישראל",
    "sameAs": "https://www.manpower.co.il",
    "logo": "https://www.manpower.co.il/_next/static/media/logo-manpower-white.b713aa15.svg"
  },
  "jobLocation": {
    "@type": "Place",
    "address": {
      "@type": "PostalAddress",
      "addressLocality": "[עיר]",
      "addressRegion": "[אזור]",
      "addressCountry": "IL"
    }
  },
  "baseSalary": {
    "@type": "MonetaryAmount",
    "currency": "ILS",
    "value": {
      "@type": "QuantitativeValue",
      "minValue": [MIN],
      "maxValue": [MAX],
      "unitText": "MONTH"
    }
  },
  "directApply": true,
  "applicationContact": {
    "@type": "ContactPoint",
    "telephone": "+972-3-563-9999"
  }
}
📌 הערות ליישום:
  • יישום דינמי ב-Next.js - סכמה נפרדת לכל משרה
  • baseSalary אופציונלי - להוסיף רק אם השכר מפורסם
  • validThrough חייב להיות תאריך עתידי
  • employmentType: FULL_TIME, PART_TIME, CONTRACTOR, TEMPORARY, INTERN

🔧 פריטים קיימים שדורשים תיקון

Article Schema 🟠 גבוה
עמודי יעד: כל 62 כתבות הבלוג
דוגמה: https://www.manpower.co.il/article/קורות-חיים
מה קיים כרגע:
• Article Schema קיים בעמודי /article/
• כולל: headline, description, articleBody
• FAQPage Schema קיים בחלק מהכתבות

⚠️ שדות חסרים (דורשים תיקון):

  • datePublished - תאריך פרסום חסר (מוצג כ-null)
  • dateModified - תאריך עדכון חסר
  • author - מחבר לא מוגדר כראוי
  • publisher - מפרסם לא מוגדר עם logo
  • image - מערך תמונות חסר
  • mainEntityOfPage - זיהוי עמוד ראשי חסר

קוד JSON-LD מתוקן:

{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "[כותרת הכתבה]",
  "description": "[תיאור קצר / meta description]",
  "image": [
    "[URL תמונה ראשית]"
  ],
  "datePublished": "[YYYY-MM-DDTHH:MM:SS+03:00]",
  "dateModified": "[YYYY-MM-DDTHH:MM:SS+03:00]",
  "author": {
    "@type": "Organization",
    "name": "מנפאואר ישראל",
    "url": "https://www.manpower.co.il"
  },
  "publisher": {
    "@type": "Organization",
    "name": "מנפאואר ישראל",
    "logo": {
      "@type": "ImageObject",
      "url": "https://www.manpower.co.il/_next/static/media/logo-manpower-white.b713aa15.svg"
    }
  },
  "mainEntityOfPage": {
    "@type": "WebPage",
    "@id": "[URL מלא של הכתבה]"
  },
  "articleSection": "[קטגוריה]",
  "inLanguage": "he-IL"
}
📌 פעולות נדרשות:
  • עדכון template ב-Next.js להוספת השדות החסרים
  • וידוא שכל כתבה מכילה תאריך פרסום במקור הנתונים
  • הוספת logic לעדכון dateModified בעת שינוי תוכן
  • וידוא ש-62 הכתבות מקבלות את הסכמה המעודכנת

🔮 דורש בדיקה ידנית

הפריטים הבאים לא ניתנו לאימות מלא - נדרשת בדיקה ידנית:

Video Schema / VideoObject 🔵 בינוני
מדוע לא אומת:
• הדוח המקורי מזכיר Video Sitemap
• לא נמצאו סרטונים מוטמעים בעמודים שנסרקו
• לא ניתן לאמת אם קיימים סרטונים בעמודים אחרים
• דורש בדיקה ידנית של עמודים עם תוכן וידאו

מה לבדוק ידנית:

  1. האם קיימים סרטוני YouTube מוטמעים באתר?
  2. האם קיים Video Sitemap ב-/video-sitemap.xml?
  3. האם עמודי קריירה כוללים סרטוני הדרכה?
  4. אם קיימים סרטונים - האם יש להם VideoObject Schema?
📌 אם נמצאים סרטונים ללא סכמה:

יש להוסיף VideoObject Schema לכל עמוד עם וידאו מוטמע. ראה תבנית בדוח המקורי.
