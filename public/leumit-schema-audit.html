להלן 2 בלוקי <script type="application/ld+json"> נפרדים. יש להוסיף את שניהם באזור ה-<head> של דף הבית. לא לגעת בסכמת ה-Organization הקיימת. שתי הסכמות מקושרות אליה — WebSite דרך publisher, ו-MedicalOrganization דרך parentOrganization.

סכמה 1: WebSite

סכמה חדשה — להוסיף

סכמת WebSite לא קיימת באתר. יש להוסיף אותה באזור ה-<head> של דף הבית. מגדירה את האתר כישות ב-Google ומקשרת אותו לסכמת ה-Organization הקיימת דרך publisher.

שדות:
  • @type: WebSite
  • @id: #website — מזהה ייחודי
  • name + alternateName: שם האתר בעברית ובאנגלית
  • inLanguage: he-IL
  • publisher: מקושר ל-#organization הקיים
application/ld+json — WebSite

{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "@id": "https://www.leumit.co.il#website",
  "name": "לאומית שירותי בריאות",
  "alternateName": "Leumit Health Services",
  "url": "https://www.leumit.co.il",
  "description": "קופת חולים לאומית - שירותי בריאות, רפואה מתקדמת, ביטוח משלים ושירותים דיגיטליים",
  "inLanguage": "he-IL",
  "publisher": {
    "@id": "https://www.leumit.co.il#organization"
  }
}
</script>

סכמה 2: MedicalOrganization

סכמה חדשה — להוסיף

סכמה חדשה לחלוטין שיש להוסיף. מגדירה את לאומית כארגון רפואי עם התמחויות וקבלת מטופלים חדשים, ומקשרת חזרה לסכמת ה-Organization הראשית באמצעות parentOrganization.

שדות חדשים:
  • @type: MedicalOrganization
  • @id: #medical-organization — מזהה ייחודי נפרד
  • medicalSpecialty: PrimaryCare + CommunityHealth
  • isAcceptingNewPatients: true
  • parentOrganization: מקושר ל-#organization
  • makesOffer: רפואה ראשונית, רפואה מתקדמת, ביטוח משלים, שירותים דיגיטליים
