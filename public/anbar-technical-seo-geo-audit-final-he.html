יכולת סריקה ואינדוקס

  • קובץ robots.txt מאפשר גישה לבוטים של AI (GPTBot, ChatGPT-User, OAI-SearchBot)
  • הפניית HTTP → HTTPS: קוד 301 (עובד)
  • הפניית www → non-www: קוד 301 (עובד)
  • טיפול נכון בשגיאות 404 (מחזיר HTTP 404, לא soft 404)
  • מפת אתר XML תקינה עם 104 כתובות ב-3 מפות משנה
  • עקביות בלוכסן נגרר (תמיד עם /)
  • עמודי חיפוש מוגנים עם noindex,follow
  • לכל העמודים יש תגיות canonical (באמצעות Yoast SEO)

סיכום אמינות הסריקה

האתר ניתן לסריקה באופן אמין. כל הדרישות הטכניות מתקיימות.

  • robots.txt: תקין, בוטי AI מורשים
  • מפת אתר: XML תקין, 104 כתובות
  • הפניות: HTTP/HTTPS + www/non-www עובדות
  • טיפול ב-404: סטטוס HTTP 404 תקין
  • תגיות Canonical: קיימות בכל העמודים
  • עמודי חיפוש: מוגנים עם noindex
