לעמוד ספציפי: הוסף ב-Head component של העמוד הרלוונטי.

פורמט: <script type="application/ld+json">{JSON}</script>

HubSpot (ManpowerGroup)

Sitewide: Settings → Website → Pages → Site Header HTML

לעמוד ספציפי: Settings → Website → Pages → Advanced options → Head HTML

פורמט: <script type="application/ld+json">{JSON}</script>

WordPress (ManpowerCare)

Sitewide: Rank Math / Yoast SEO מייצר אוטומטית.

לעמוד ספציפי: הוסף דרך Rank Math → Schema → Custom JSON-LD, או בלוק HTML מותאם.
