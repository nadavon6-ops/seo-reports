// WRONG - מפנה לדומיין אחר:
{
  "@type": "WebSite",

  }
}

  "name": "ManpowerGroup Israel",
  "url": "https://manpowergroup.co.il/",
  "inLanguage": "he-IL",
  "publisher": {
    "@id": "https://manpowergroup.co.il/#organization"

    "@type": "SearchAction",
    "target": {
      "@type": "EntryPoint",

      "@type": "PropertyValueSpecification",
      "valueRequired": true,

SearchAction - חסר מתוך WebSite Schema הקיים

עדיפות בינונית
ראיה: האתר מכיל תיבת חיפוש גלויה (WordPress ?s=) אך הסכמת WebSite הקיימת לא כוללת SearchAction.
עדכון WebSite Schema - הוסף SearchAction:
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "@id": "https://talentsolutions.manpowergroup.co.il/#website",
  "url": "https://talentsolutions.manpowergroup.co.il/",
  "name": "Talent Solutions Israel",
  "inLanguage": "he-IL",
  "publisher": {
    "@id": "https://talentsolutions.manpowergroup.co.il/#organization"
  },
  "potentialAction": {
    "@type": "SearchAction",
    "target": {
      "@type": "EntryPoint",
      "urlTemplate": "https://talentsolutions.manpowergroup.co.il/?s={search_term_string}"
    },
    "query-input": {
      "@type": "PropertyValueSpecification",
      "valueRequired": true,
      "valueName": "search_term_string"
    }
  }
}

מיקום: WordPress - עדכן את הסכמה הקיימת ב-header או דרך Rank Math.
