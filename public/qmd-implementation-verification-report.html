5Hreflang tags missingSite-wide
No hreflang tags anywhere on the site. QMD operates facilities in six countries (US, Israel, Germany, France, Slovakia, India) and serves those markets from a single English site. Add self-referencing hreflang with x-default so Google understands the single-language, multi-market setup.
6Leadership duplicate needs a 3011 URL
The duplicate was handled by setting qmd.net/leadership/ to noindex and removing it from the sitemap, which resolves the indexing conflict. The instruction was a 301 redirect to qmd.net/qmd-leadership/. The redirect is still worth doing: it consolidates any link signals to the surviving page and removes the duplicate permanently instead of leaving a live, crawlable copy. The old member pages under /leadership/ are also still live and noindexed and should redirect too.
7Homepage image ALT text5 of 11 images
ALT text was added across the rest of the site, but 5 of the 11 homepage images still have an empty ALT attribute. Add descriptive ALT text to each, or keep it empty only where the image is genuinely decorative.
8Performance items not applied2 items
Server response time is now fast and images use responsive srcset with lazy loading, so the main performance work landed. Two recommendations were not applied: none of the 36 scripts in the head carry a defer attribute, and no images are served in WebP or AVIF.
