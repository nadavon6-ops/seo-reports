Server error (HTTP 500) on /מטפלות-מתעללות/
The problem: midot.co.il/מטפלות-מתעללות/ (page ID 1231), listed in page-sitemap.xml, returns HTTP 500. The page prints the site header and menu, then stops with the WordPress message "באתר זה אירעה שגיאה קריטית". The status code is the same for a regular browser and for the Googlebot user agent. It is the only URL in the sitemap that fails.

Where the error is

The page uses the custom page template template-page/caretakers.php in the midot-th theme. A HEAD request to the URL returns 200 and a GET returns 500. WordPress answers HEAD requests before it loads the template, so the fatal error is raised while the page itself is being rendered. Since no other page fails, this template, or something it calls, is the most likely source.

What to do

  1. In wp-config.php set WP_DEBUG and WP_DEBUG_LOG to true and WP_DEBUG_DISPLAY to false, open the URL, then read wp-content/debug.log. The fatal error line names the file and line.
  2. Fix the error at the file and line the log names (most likely template-page/caretakers.php) so the page returns 200 with its content.
  3. If the page is not meant to be public, unpublish it instead and confirm it no longer appears in page-sitemap.xml.

Acceptance: a GET request to the URL returns 200 with the page content, or the page is unpublished and no longer listed in the sitemap.
