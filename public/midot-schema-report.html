2. Core issue: FAQ schema Partly done

Status: partly done. 23 pages now output FAQ schema correctly. Remaining: one post shows the code as text, and the same mistake has now happened on two new posts.

The problem: on the post midot.co.il/מתי-ראיון-עבודה-רגיל-לא-מספיק-כדי-למנוע/, the FAQ code was pasted into the page's schema field without the <script type="application/ld+json"> wrapper. Visitors see the raw JSON printed on the page (in section.section-schema), and search engines get no FAQ schema. The code itself is valid and matches the page's 5 questions and answers.

What to do

  1. Replace the contents of that post's schema field with the block below: the same 5 questions and answers, wrapped in the script tag. Do not add it as a second block, or the raw text stays on the page.
  2. Prevent it from happening again: in the template that prints the schema field, wrap the field's contents in <script type="application/ld+json"> … </script> whenever they do not already start with <script. Editors can then paste the JSON alone, and the 23 pages whose field already includes the tag are not affected.
