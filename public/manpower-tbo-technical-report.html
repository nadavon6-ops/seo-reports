2. Canonical, Indexing ו-Hreflang

9 בעיות
P0 תגית Canonical חסרה בכל 7 הדפים
אף דף מ-7 דפי TBO לא מכיל <link rel="canonical">. ללא Canonical, גוגל עלול לאנדקס גרסאות כפולות (trailing slash, query params, etc.).
תיקון ב-Next.js: יש להוסיף ב-_app.js או ב-Head component:
<link rel="canonical" href={canonicalUrl} />
כל דף צריך canonical המצביע על עצמו.
P2 Hreflang חסר - גרסאות אנגליות קיימות
מספר דפים (לוגיסטיקה, ייצור, תעשייה) מכילים metadata של slug אנגלי אך ללא תגיות hreflang מתאימות. עדיפות נמוכה אלא אם הגרסאות האנגליות פעילות.
P2 Robots meta תקין בכל הדפים
כל 7 הדפים מוגדרים index, follow - תקין. אין noindex שגוי.

3. Schema / JSON-LD

14 בעיות
P0 BreadcrumbList שבור בכל 7 הדפים
3 בעיות בכל BreadcrumbList:
  1. פריט ראשון ("בית") חסר "item" URL - חובה לפי schema.org
  2. שם פריט אחרון = כותרת הדף המלאה, במקום שם קצר
  3. חסרה רמת ביניים "פתרונות למעסיקים" (2 רמות במקום 3)
תיקון נדרש:
{"position":1, "name":"בית", "item":"https://www.manpower.co.il/"}
{"position":2, "name":"פתרונות למעסיקים", "item":"https://www.manpower.co.il/employers-solutions/"}
{"position":3, "name":"[שם דף קצר]"} ← ללא item (פריט אחרון)
P0 אין FAQPage Schema - למרות FAQ קיים בדף TBO ראשי
דף TBO ראשי מכיל 4 שאלות ותשובות מלאות אך ללא FAQPage JSON-LD. זהו תיקון של 5 דקות שיכול להכפיל את שטח ה-SERP.
יש להוסיף FAQPage schema עם 4 Question/Answer objects. ב-6 הדפים האחרים - יש קודם ליצור מקטע FAQ ואז להוסיף schema.
P1 אין Service Schema באף דף שירות
כל 7 הדפים הם דפי שירות (מוקדים, לוגיסטיקה, ייצור וכו') אך אף אחד לא מכיל @type: Service schema.
יש להוסיף Service schema עם serviceType, provider, areaServed לכל דף.
P2 Organization Schema קיים - תקין
Organization schema מלא: שם, כתובת, טלפון, sameAs (Facebook, Instagram, LinkedIn). הערה: לוגו הוא SVG שגוגל עלול לא לרנדר - שווה להוסיף PNG.
P2 אין WebSite Schema
חסר WebSite schema ברמת האתר. לפי ה-CLAUDE.md, manpower.co.il לא צריך SearchAction (סינון עבודות, לא חיפוש רגיל) - אבל WebSite בלבד כן מומלץ.

6. לינקים פנימיים

3 בעיות
P1 טקסט עוגן גנרי "להמשך קריאה" x21
כל סיפורי ההצלחה בכל 7 הדפים משתמשים ב-"להמשך קריאה" - 3 לינקים פנימיים בכל דף = 21 לינקים ללא ערך SEO.
יש להחליף ל-anchor text תיאורי:
"להמשך קריאה" ← "קראו על ניהול מוקד עבור מגדל ביטוח"
"להמשך קריאה" ← "סיפור ההצלחה של NOVA - תחזוקת חדרים נקיים"
P2 אין לינקים פנימיים הקשריים בתוך הטקסט
בכל 7 הדפים, הלינקים הפנימיים הם רק מה-nav, footer, וכפתורי "להמשך קריאה". אין לינקים הקשריים בתוך הפסקאות. למשל: בדף לוגיסטיקה אין לינק לדף ייצור או ל-TBO ראשי מתוך הטקסט.
P2 Nav ו-Footer - מבנה תקין
50+ לינקים פנימיים ב-footer עם anchor text מילות מפתח. מבנה Nav תקין עם לינקים לכל דפי השירות. External links ל-ManpowerGroup, Talent Solutions, Experis - ללא nofollow (תקין).
