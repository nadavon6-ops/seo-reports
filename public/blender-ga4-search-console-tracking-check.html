כתובות www: www.blender.global לא נטען, ו-www.blenderpay.com מפנה בהפניה זמנית

עדיפות 3
אתר ונכסwww.blender.global (S3 + CloudFront) · www.blenderpay.com · נכסי Search Console blender.global ו-blenderpay.com
מה לא תקיןhttps://www.blender.global נכשל עוד לפני טעינת העמוד: תעודת ה-SSL מכסה רק את blender.global, ולכן הדפדפן מציג שגיאת חיבור. http://www.blender.global מחזיר 403. רק http://blender.global מפנה כראוי ב-301 לכתובת הראשית. ב-blenderPay, https://www.blenderpay.com מפנה ל-https://blenderpay.com ב-302 (הפניה זמנית) ולא ב-301.
השפעה על המדידהגולש או קישור שמגיעים ל-www.blender.global נתקלים בשגיאה במקום באתר, ולא נמדדים ב-GA4. הפניה זמנית ב-www.blenderpay.com לא מאחדת באופן קבוע את גרסת ה-www עם הכתובת הראשית.
מה לתקןלהפנות את שתי גרסאות ה-www ב-301 לכתובת הראשית, עם תעודת SSL תקינה ל-www.blender.global.
הוראות טכניות
  1. ב-AWS Certificate Manager (אזור us-east-1): תעודה שמכסה את blender.global ואת www.blender.global, ולצרף אותה להפצת ה-CloudFront.
  2. להוסיף את www.blender.global כ-Alternate domain name בהפצה, ולהגדיר הפניית 301 ל-https://blender.global עם אותו נתיב (CloudFront Function על viewer request, שבודקת את שם המארח ושומרת את הנתיב ואת הפרמטרים), גם מ-http וגם מ-https.
  3. ב-blenderpay.com: לשנות את ההפניה מ-www.blenderpay.com ל-301 אל https://blenderpay.com/ (אותו נתיב).
בדיקת קבלהcurl -sI https://www.blender.global/ ו-curl -sI http://www.blender.global/ מחזירים 301 עם location: https://blender.global/. curl -sI https://www.blenderpay.com/ מחזיר 301.
