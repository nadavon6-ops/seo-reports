🔍 Methodology Improvements (V2)

Lessons Learned from V1 Errors
  • HTML Entity Encoding: Next.js sites often use &quot; encoding in JSON-LD. Search for both plain and encoded formats.
  • Dynamic Loading: Schemas with strategy="afterInteractive" or script IDs should be searched by ID, not just @type.
  • Multi-Page Verification: Always verify findings on 3+ pages before concluding sitewide issues.
  • Mixed Results: Don't assume all pages have the same issue - verify individually when possible.
