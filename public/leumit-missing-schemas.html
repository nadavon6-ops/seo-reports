1 Organization Schema - כל האתר עדיפות גבוהה חסר

עמודיםכל עמודי האתר
מיקוםבתוך <head> - Master Template (Header גלובלי)
מטרהKnowledge Panel בגוגל, אמינות ארגונית

2 BreadcrumbList Schema (דינמי) עדיפות גבוהה חסר

עמודיםכל העמודים באתר (מלבד עמוד הבית)
מיקוםMaster Template - בתוך <head>
סוגדינמי - נבנה אוטומטית לפי מבנה האתר
שימו לב: הפריט האחרון (העמוד הנוכחי) מכיל רק "name" ללא "item"!

דוגמה לעמוד מחלה:

<script type="application/ld+json"> { "@context": "https://schema.org", "@type": "BreadcrumbList", "itemListElement": [ { "@type": "ListItem", "position": 1, "name": "דף הבית", "item": "https://www.leumit.co.il/" }, { "@type": "ListItem", "position": 2, "name": "מחלות", "item": "https://www.leumit.co.il/diseases/" }, { "@type": "ListItem", "position": 3, "name": "חצבת" } ] } </script>

דוגמה לעמוד צור קשר:

<script type="application/ld+json"> { "@context": "https://schema.org", "@type": "BreadcrumbList", "itemListElement": [ { "@type": "ListItem", "position": 1, "name": "דף הבית", "item": "https://www.leumit.co.il/" }, { "@type": "ListItem", "position": 2, "name": "צור קשר" } ] } </script>

3 FAQPage Schema + תוכן FAQ בעמוד - כסף וזהב עדיפות בינונית חסר

עמודhttps://www.leumit.co.il/insurance-policies/leumit-silver-and-gold/
מיקום Schemaבתוך <head> של העמוד
מטרהFAQ Rich Results בגוגל
חשוב - נדרשות שתי פעולות:
  1. הוספת תוכן FAQ נראה בעמוד: כרגע אין שאלות ותשובות בעמוד עצמו. יש להוסיף סקשן שאלות נפוצות עם השאלות והתשובות שמופיעות למטה.
  2. הוספת FAQPage Schema: להוסיף את קוד ה-JSON-LD ל-head של העמוד. התוכן חייב להתאים בדיוק לתוכן הנראה בעמוד.
