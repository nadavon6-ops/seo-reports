8 UX & SEO Notes

Hierarchy

Single H1 · distinct H2s per major block · H3s inside Benefits / Capabilities / Products. Source uses bold for everything — enforce real heading tags.

Readability

Paragraphs ≤ 3 lines. Bullet lists inside Benefits and Capabilities (already done — keep).

Above-the-fold (desktop)

H1 + subtitle + primary CTA + diagram visible without scroll.

Mobile

Capability grid → 2 columns (not 3). Product cards stacked vertically with consistent height.

Intent alignment

Mid-funnel buyer evaluating platforms. Keep "Let's talk data" as primary CTA. Add a softer secondary ("Watch the demo" / "Download the data sheet") for top-of-funnel readers.

Schema (JSON-LD)

Product × 3 · FAQPage · BreadcrumbList

GEO / AI search readiness

Add the short definitional passage near the top. Keep capability and product descriptions self-contained (so an LLM can cite a single passage). Use plain language in the diagram caption.

Internal linking

Each Capability → its product page on qlik.com · Each Product → its dedicated page · Add "Related solutions" block at the bottom.
