QMD Homepage: SEO Adjustments

Implementation Spec for the Approved Target Queries
qmd.net · homepage only · remaining pages follow after approval

Approved Target Queries

medical device contract manufacturing
650 global searches/month
medical device component manufacturer / finished device
140 global searches/month (component manufacturer)
Where the homepage stands today: neither phrase appears anywhere on the page. The title tag starts with the word "Homepage", there is no meta description, and the H1 carries no service terms. As a result the homepage currently ranks for brand searches only (qmd, qmd medical, degania silicone). The adjustments below place both approved queries in the positions Google weighs most, without changing the page design.

Note on "finished device": phrasings like "finished device manufacturer" carry no measurable standalone search volume, so "finished device" is woven into the copy as a supporting term rather than targeted separately. It strengthens relevance for the component/finished-device query pair the client approved.

Adjustments

1

SEO Title

Yoast SEO › Homepage › SEO title
Current
Homepage - QMD: Silicone & Polyisoprene Elastomer Manufacturer
Replace with
Medical Device Contract Manufacturing & Components | QMD
56 characters, displays in full on desktop and mobile
Why: the word "Homepage" currently occupies the highest-weight position in the title. The replacement leads with approved query 1 verbatim and adds "Components" to support query 2. Yoast mirrors this into og:title automatically.
2

Meta Description

Yoast SEO › Homepage › Meta description
Current
Empty. No page on qmd.net has a meta description; Google picks the snippet text itself, usually poorly matched to the query.
Replace with
QMD provides medical device contract manufacturing, from precision silicone components to finished devices. FDA, CE, 510(k) and Canadian regulatory approvals.
158 characters, within typical snippet display length
Why: contains approved query 1 verbatim plus the components-to-finished-devices span of query 2, and gives Google a ready-made, relevant snippet for these queries (Google may still adjust it). The regulatory approvals match the ones already published on the homepage.
3

H1 Heading

Elementor › hero section heading widget
Current
Solutions to Bring Your Medical Devices to Market
Replace with
Medical Device Contract Manufacturing, from Components to Finished Devices
Why: the H1 is one of the strongest on-page relevance signals. This version states approved query 1 verbatim and covers the component-to-finished-device range in one natural sentence. The supporting paragraph below the H1 can stay as is.
4

Intro Paragraph ("Trusted Partner" section)

Elementor › text widget under the "Trusted Partner. Unrivaled Silicone Expertise." heading
Current
No one knows silicone like we do. Our roots manufacturing elastomeric components and devices go back decades, enabling our team to create optimal solutions for complex challenges.
Replace with
No one knows silicone like we do. As a medical device component manufacturer with roots going back decades, we deliver everything from precision elastomeric components to finished devices, creating optimal solutions for complex challenges.
Why: places approved query 2 verbatim in the first body paragraph while keeping the sentence rhythm and brand voice of the original.
5

Card Headings + Heading Levels

Elementor › "Tailored Solutions to Meet Your Needs" cards
Current
Three cards titled "Component Manufacturing", "Device Manufacturing", "Private Labeling", all rendered as <h5> directly under an <h2> (skips two heading levels).
Replace with
1. Rename "Device Manufacturing" to "Finished Device Manufacturing". "Component Manufacturing" and "Private Labeling" keep their names.
2. In each of the three heading widgets, change the HTML tag from h5 to h3 (Elementor heading widget › HTML Tag). Visual size is controlled by the style settings and does not change.
Why: "Finished Device Manufacturing" turns the card into an exact signal for the approved finished-device query, and a clean h1>h2>h3 hierarchy gives crawlers and screen readers a clean outline of the service structure. Locator note: the current widget text contains a manual line break ("Device<br>Manufacturing"), which is how to spot the exact heading widget in Elementor.

Organization Schema Enrichment

child theme functions.php or a code snippets plugin
Current
Yoast outputs a minimal Organization node: name, url and logo only. No description, no service terms, no served regions.
Add this filter (extends the existing Yoast node, no duplicate schema is created)
add_filter( 'wpseo_schema_organization', function( $data ) {
  $data['description'] = 'QMD is a medical device contract manufacturing partner: '
    . 'a medical device component manufacturer and finished device producer '
    . 'specializing in silicone and polyisoprene elastomers.';
  $data['knowsAbout'] = array(
    'medical device contract manufacturing',
    'medical device components',
    'finished device assembly',
    'silicone molding and extrusion',
    'polyisoprene elastomers',
  );
  $data['areaServed'] = array( 'US', 'IL', 'DE', 'FR', 'IN' );
  return $data;
} );
Why: the enriched node tells search and AI engines what QMD does and where, using the approved queries. The five country codes match the facilities listed on qmd.net/locations/ (USA, Israel, Germany, France, India). If QMD maintains an official LinkedIn page, add it as a sameAs array entry; we found no social profiles linked on the site, so none were included.

After Publishing

  • Purge the WP Rocket cache (Settings › WP Rocket › Clear cache), otherwise the old title and headings will continue to be served.
  • View the page source and confirm: the new title tag, the meta description present, exactly one H1, card headings as h3, and alt text present on the images listed in item 7.
  • In Google Search Console, run URL Inspection on qmd.net and click "Request indexing" so the changes are picked up quickly.
  • og:title and og:description update automatically through Yoast; no separate change is needed.
