א. קודי HTML גולמיים בתוך טקסט הסכמות

בחלק מהבלוקים הטקסט כולל קודי HTML שלא פוענחו (&#8211;, &quot;, &nbsp;), ובתשובות ה-FAQ גם תגיות HTML מלאות (<p>, <span style=…>). גוגל קורא את הטקסט כפי שהוא, כולל הקודים.

הפעולה: לנקות את הטקסט פעם אחת, בפונקציה שמדפיסה את כל בלוקי הסכמה, כך שהתיקון יחול על כל הסוגים ועל עמודים עתידיים. אותו ניקוי פותר גם את התקלה בסעיף ג.

קוד לניקוי הטקסט
// בפונקציה שמדפיסה את בלוקי הסכמה (בקוד הדוגמה שמסרנו היא נקראה karkur_print_schema;
// יש להחיל את הניקוי בפונקציה המקבילה בקוד הקיים), לנקות כל ערך טקסט לפני ההדפסה:
function karkur_clean_schema_text( $v ) {
    if ( is_array( $v ) ) {
        return array_map( 'karkur_clean_schema_text', $v );
    }
    if ( ! is_string( $v ) ) {
        return $v;
    }
    $v = html_entity_decode( $v, ENT_QUOTES | ENT_HTML5, 'UTF-8' ); // &#8211; → –, &quot; → "
    $v = preg_replace( '/<[^>]+>/', ' ', $v );                     // תגיות → רווח, כדי שמילים לא יתחברו
    $v = str_replace( "\xC2\xA0", ' ', $v );                       // רווח קשיח → רווח רגיל
    return trim( preg_replace( '/\s+/u', ' ', $v ) );
}

// ולפני כל wp_json_encode של בלוק סכמה:
$data = karkur_clean_schema_text( $data );
echo '<script type="application/ld+json">'
    . wp_json_encode( $data, JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES )
    . '</script>';

ב. פירורי לחם: סימון ישן ושגוי, ו-56 עמודים ללא סימון תקין

תבנית פירורי הלחם הגלויה מסומנת ב-Microdata חלקי: 2,121 רכיבי ListItem ב-582 מתוך 611 עמודים, בלי מיכל BreadcrumbList, עם מיקום שמתחיל ב-0 ועם url במקום item. ב-545 מהעמודים האלה קיים במקביל BreadcrumbList תקין ב-JSON-LD, שגוגל מזהה, כך שהסימון הישן הוא כפילות לא תקינה.

בשני סוגי עמודים אין BreadcrumbList ב-JSON-LD כלל: 37 ארכיוני הקטגוריות (שבהם הסימון הישן הוא היחיד) ו-19 עמודי האירועים.

הפעולה, בשני חלקים שיש לבצע יחד:

  1. להסיר את מאפייני ה-Microdata מתבנית פירורי הלחם. התצוגה בעמוד נשארת כפי שהיא.
  2. להרחיב את קוד ה-JSON-LD הקיים של BreadcrumbList לארכיוני הקטגוריות ולעמודי האירועים, כדי שגם בהם יהיה סימון תקין לאחר ההסרה.
