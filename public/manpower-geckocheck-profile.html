Read first

  • Manpower is not in GeckoCheck yet. GeckoCheck staff create the brand from section 01; the account role is User and has no setup screen. The CSV files at the bottom are ready for a bulk import.
  • Two audiences, one brand. Job seekers (jobs, salary, CV, interviews) and employers (recruitment, outsourcing, payroll) ask very different questions. Categories, personas and the query set are split so each side gets its own score. Do not merge them into one category.
  • No Google Search Console data. The GSC property www.manpower.co.il has returned a permission error (unverified) for our account since 22.09.2026, so demand comes from SE Ranking tracked keywords, the SE Ranking Data API and Ahrefs Israel. SE Ranking volume is shown everywhere; Ahrefs volume appears only where SE Ranking has none. B2B outsourcing terms sit below the volume database threshold, so a few employer queries are strategic, marked hypothesis.
  • Sister brands are not spellings of Manpower. ManpowerGroup, Experis, Manpower Care and Talent Solutions are separate brands. Manpower Care is written מנפאואר קר, which contains מנפאואר: exclude the phrases מנפאואר קר and Manpower Care from Manpower brand-mention matching, or care-sector answers will count as Manpower mentions.
  • כוח אדם is not a brand spelling. It is the Hebrew for manpower and the generic name of the whole staffing category.
  • Several competitor Hebrew names are ordinary words (דרושים, נישה, תיגבור, דיאלוג, נקודת פתיחה). Match those competitors on their Latin names and domains, never on the bare Hebrew word.
  • The core set is 50 queries (13 branded, 37 unbranded). The full set adds 31 more for a larger plan. Retention and Referral are light by nature for a staffing brand: they cover pay reviews, placement follow-up and the refer-a-friend programme.
