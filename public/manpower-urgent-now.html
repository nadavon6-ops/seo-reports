7 תיקון WebSite Schema קיים (הוספת שדות חסרים, הסרת SearchAction)
היכן עמוד הבית בלבד
למה חסרים @id, inLanguage, publisher; SearchAction לא מתאים
אחראי פיתוח
מאמץ S
עמוד לתיקון
manpower.co.il/ (עמוד הבית)
אומת: WebSite schema קיים עם SearchAction. חסרים @id, inLanguage, publisher, alternateName. יש להסיר SearchAction (אין תיבת חיפוש גלויה).
להחליף את ה-WebSite schema הקיים ב:
{ "@context": "https://schema.org", "@type": "WebSite", "@id": "https://www.manpower.co.il/#website", "name": "Manpower Israel", "alternateName": "מנפאואר ישראל", "url": "https://www.manpower.co.il/", "description": "חברת כוח אדם מובילה בישראל - גיוס, השמה, מיקור חוץ ופתרונות תעסוקה", "inLanguage": "he-IL", "publisher": { "@id": "https://www.manpower.co.il/#organization" } }
יש להסיר את בלוק potentialAction / SearchAction הקיים לחלוטין.
