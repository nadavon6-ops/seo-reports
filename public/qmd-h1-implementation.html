QMD — Add a Main Heading (H1) to 14 Product Pages
Fourteen product pages have no main heading. Each one opens with a second-level heading (H2) instead, so the page never states its own subject in the place search engines weigh most heavily after the title. On eleven pages the heading text is also being replaced; on three it stays exactly as it is and only the tag changes.
Every new heading was set against six months of this site's own Search Console data and against what each page actually sells, so each one leads with a term the page already earns impressions for. The reason is given under each page.
Current headings verified on the live site on 16 September 2026  ·  Working sheet: QMD — H1 Heading Implementation
1How to make the changeRead first
The change on every page is the same: the heading that is already there becomes the page's H1. Do not add a new heading above it, and do not create a second one.
  1. Open the page in Elementor.
  2. Click the heading listed as the current heading for that page.
  3. If the page is in the first group below, replace its text with the new heading exactly as written.
  4. In the left-hand panel, change the setting called HTML Tag from H2 to H1.
  5. Save and publish.
Do not change the design.HTML Tag changes only what the heading is called in the page code, not how it looks. Font, size, colour, weight, spacing and position must stay exactly as they are now. If the heading renders differently after the switch because the theme styles H1 separately, set it back manually under Style — do not leave it changed.
One H1 per page.After the change each page must have exactly one H1: the heading named for that page. None of the fourteen pages has an H1 today, so setting this one leaves exactly one. Do not set any other heading on the page to H1.
Publish the wording exactly as written.Capitalisation, punctuation and the dash are part of the text. Each heading was chosen against real query data, so paraphrasing it loses the term it was built around.

4Check when you are finishedPer page
  • The page has exactly one H1, and it is the heading named for that page.
  • No second heading was added above or below it.
  • The heading looks the same as it did before — same font, size, colour, weight, spacing and position.
  • For the eleven reworded pages, the text matches the new heading exactly, including capitalisation and punctuation.
  • The heading was not paraphrased or shortened to fit the design.
  • For the three tag-only pages, the text is untouched.
  • The page is published, not left as a draft revision.
A quick way to confirm on a live page: right-click the heading, choose Inspect, and check the element reads <h1>. Mark each row Done in the working sheet as you go, and mark anything you could not complete as Issue rather than leaving it Not started.
On some pages the new heading and the page title are deliberately worded differently. The urinary catheters page is headed “Silicone Urinary Catheters” while its title says “Silicone Foley Catheters”. That is intentional, not an error — both phrasings are accurate and it lets one page cover two ways buyers search.
