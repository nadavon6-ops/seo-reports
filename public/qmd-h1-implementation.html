QMD — Add a Main Heading (H1) to 14 Product Pages
None of these 14 pages has a main heading today — each one opens with a second-level heading (H2). On every page the heading becomes the page's H1. On seven pages the heading text is also replaced; on the other seven the text stays exactly as it is and only the tag changes. Both are listed below, in the order they appear in the client's file.
Change the tag, not the design. Changing the heading from H2 to H1 changes only what the heading is called in the page code, not how it looks. Font, size, colour, weight, spacing and position must stay exactly as they are. Do not add a new heading above the existing one, and after the change each page must have exactly one H1.
