הבהרה טכנית: קוד FAQ Schema באתר mhaim1.com

מענה לבקשת צוות הפיתוח (קאש קאו) להבהרה בנוגע לסעיף 4 בדוח ההמלצות
אוגוסט 2026
צוות קאש קאו ביקש לדעת מה בדיוק לא תקין בקוד ה־Schema הקיים, איזה קוד נמצא, ומה אמור להחליף אותו. המסמך עונה על שלוש השאלות לפי הסדר, וכולל קוד מוכן להעתקה. הבדיקה בוצעה על 4,324 עמודים מתוך מפת האתר (sitemap), בשילוב רינדור מלא בדפדפן (Chrome headless) לאימות מול מה שגוגל רואה בפועל.
1. הקוד השגוי שנמצא והיכן הוא מופיע▼

בתוך בלוק ה־CSS המותאם של האתר (קוד שנטען כחלק מתגית <style> בכל עמוד) מוטמע המקטע הבא, כלשונו:

<script type="application/ld json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  ...
}
</script>

המקטע מופיע בסוף אחד מבלוקי ה־<style> של האתר, מיד אחרי חוקי CSS רגילים. מכיוון שמדובר בשדה CSS גלובלי, הקוד נטען בכל עמודי האתר: בסריקה שביצענו הוא נמצא ב־4,324 מתוך 4,324 עמודים שנבדקו, כלומר בכל עמודי האתר ללא יוצא מן הכלל (כל העמודים החזירו סטטוס 200 ונסרקו בהצלחה). התפוצה המלאה מאשרת שהמקור הוא שדה CSS גלובלי אחד.

2. מה לא תקין בקוד▼

שלושה כשלים נפרדים, שכל אחד מהם לבדו מונע מהקוד לתפקד:

  1. הקוד יושב בתוך תגית <style>. דפדפנים ומנועי חיפוש מפרשים את כל התוכן שבתוך style כטקסט CSS. תגית script בתוך style אינה הופכת לאלמנט בעמוד ואינה נקראת כ־Structured Data. אימתנו זאת ברינדור מלא: ב־DOM המורנדר לא קיים אלמנט script כזה, והטקסט נשאר "לכוד" בתוך ה־CSS.
  2. סוג התגית שגוי. נכתב application/ld json במקום application/ld+json (חסר סימן החיבור). גם אם הקוד היה מחוץ ל־style, גוגל לא היה מזהה אותו כ־JSON-LD.
  3. התוכן הוא שלד ריק. בגוף הקוד מופיעות שלוש נקודות (...) במקום שאלות ותשובות. זהו JSON לא חוקי שלא ניתן לפענוח, ללא תוכן בפועל.

המשמעות: הקוד אינו תורם דבר, ובנוסף טקסט שאינו CSS בתוך גיליון הסגנונות עלול לשבש את פענוח חוקי ה־CSS שאחריו באותו בלוק. לכן ההמלצה בדוח היא הסרה.

3. מה אמור להחליף אותו▼

בתוך ה־CSS: שום דבר. המקטע פשוט נמחק משדה ה־CSS המותאם, ואין להחליפו שם בקוד אחר. חשוב באותה מידה: אין להעביר גרסה "מתוקנת" של הקוד להזרקה גלובלית (Header כלל־אתרי וכדומה). סימון FAQ חייב להיות פר־עמוד ולשקף אך ורק שאלות ותשובות שמוצגות בפועל באותו עמוד. בלוק אחיד שמוזרק לכל העמודים ייחשב שגוי בכל עמוד שבו התוכן אינו מופיע.

כך נראית הטמעה תקינה (קיימת כבר באתר)

בעמוד הקטגוריה כלי אוכל ושתייה לכלבים קיים כבר בלוק FAQ תקין: תגית <script type="application/ld+json"> בגוף העמוד, עם JSON חוקי ושש שאלות ותשובות שזהות מילה במילה לתוכן המוצג בעמוד. הבלוק הזה תקין ואין לגעת בו. זהו הפורמט המדויק לכל הטמעה עתידית:

תבנית לשימוש חוזר (לעמודים נוספים)

אם בעתיד יתווסף תוכן שאלות ותשובות לעמודים נוספים, זו התבנית, כאשר כל שאלה ותשובה חייבות להופיע גם כתוכן גלוי באותו עמוד, באותו נוסח:

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "### השאלה כפי שמופיעה בעמוד ###",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "### התשובה כפי שמופיעה בעמוד ###"
      }
    }
  ]
}
</script>

אם קאש קאו מעדיפים פתרון פלטפורמה, הדרך הנכונה היא הפקה אוטומטית של הבלוק מאותו מקור נתונים שמציג את האקורדיון בעמוד: בלוק אחד לכל עמוד, נבנה ב־JSON serializer (לא שרשור מחרוזות), ולא נפלט כלל בעמודים ללא שאלות ותשובות גלויות.

תיאום ציפיות

גוגל הפסיקה להציג תוצאות עשירות מסוג FAQ לכלל האתרים במאי 2026. הערך של הסימון כיום הוא תקינות טכנית של העמוד ונגישות התוכן למנועי חיפוש ולעוזרי AI, ולא הופעת שאלות מורחבות בתוצאות החיפוש של גוגל. לכן ברירת המחדל המומלצת היא הסרה בלבד של הקוד השגוי, והשארת הבלוקים התקינים הקיימים.

4. תיקון נקודתי נוסף: בלוק FAQ בשני עמודי קטגוריה▼

בסריקה המלאה נמצאו גם שני עמודים שבהם קיים בלוק FAQ בפורמט הנכון (script בגוף העמוד עם הסוג התקין), אך ה־JSON שבתוכו אינו עובר פענוח בגלל ירידות שורה גולמיות בתוך מחרוזות הטקסט. זו תקלה טכנית שמבטלת את הבלוק כולו. התוכן עצמו תקין ותואם לשאלות והתשובות המוצגות בעמוד; נדרשת רק החלפת הבלוק בגרסה מתוקנת.

5. יישום גורף או עמוד־עמוד▼

ניתן, וזו הדרך הנכונה. מכיוון שהקוד השגוי מגיע משדה ה־CSS המותאם הגלובלי, הוא מופיע בכל 4,324 עמודי האתר ממקור אחד. מחיקה אחת של המקטע מהשדה הזה מסירה אותו מכל האתר בבת אחת, ואין צורך לעבור עמוד־עמוד.

שתי הסתייגויות ליישום:

  • ההסרה הגורפת נוגעת אך ורק למקטע שבתוך ה־CSS. באתר קיימים 83 עמודים (עמודי קטגוריה, עמודי מדריך ועמודי מוצר) עם בלוקי FAQ תקינים שהוטמעו כחלק מתוכן העמוד, ואלה נשארים ללא שינוי.
  • שני העמודים שבסעיף 4 דורשים בנוסף החלפה נקודתית של הבלוק בקוד המתוקן המצורף.
6. בדיקת תקינות לאחר הביצוע▼

לאחר ההסרה (וניקוי Cache של הפלטפורמה/CDN) נוודא משני הצדדים:

  • אפס מופעים של המחרוזת application/ld json בקוד המקור בכל עמודי האתר.
  • לא נותר טקסט script בתוך בלוקי <style>.
  • 83 בלוקי ה־FAQ התקינים הקיימים נשארו במקומם ללא שינוי, וכן שאר בלוקי ה־JSON-LD (Organization, WebSite).
  • הבלוקים המתוקנים בעמודי חטיפים לחתולים וחטיפי אילוף עוברים פענוח JSON תקין.

אנחנו נריץ את הסריקה החוזרת מצדנו מיד לאחר שקאש קאו יעדכנו שהשינוי בוצע.
