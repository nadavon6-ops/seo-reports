תשתית SEO — תיקונים לפני השקה

קריטי להשקה ▼
Meta Descriptions — חסרים בכל הדפים
  • אף דף באתר לא מכיל meta description — Google מייצר snippet אוטומטי שלא תמיד מדויק
  • להוסיף meta description ייחודי לכל דף (150-160 תווים), עם מילות מפתח ראשיות של הדף
  • Yoast SEO מותקן באתר — להשתמש בשדה "Meta description" בכל עמוד
Canonical Tags — חסרים בכל הדפים
  • לא נמצאו canonical tags באף דף — Google עלול לסרוק גרסאות כפולות (עם/בלי trailing slash, פרמטרים)
  • Yoast SEO צריך להוסיף canonical tags אוטומטית — לוודא שההגדרה מופעלת ב-Yoast → Advanced
  • לוודא שכל דף מצביע לעצמו כ-canonical (self-referencing canonical)
הסרת Noindex — ברגע ההשקה
  • אתר הפיתוח חסום מאינדוקס (צפוי) — ברגע ההשקה יש לוודא:
  • הסרת "Discourage search engines" ב-Settings → Reading ב-WordPress
  • הסרת כל noindex tags ידניים ב-Yoast SEO
  • בדיקת robots.txt — לוודא שאין Disallow: / שחוסם את הסריקה
  • הגשת XML Sitemap ל-Google Search Console מיד לאחר ההשקה
Hreflang Tags — חסרים
  • לא נמצאו hreflang tags באתר — נדרש לאתר בעברית
  • להוסיף לכל דף: <link rel="alternate" hreflang="he" href="URL" />
  • להוסיף <link rel="alternate" hreflang="x-default" href="URL" />
  • WPML מותקן — ייתכן שניתן להגדיר hreflang אוטומטי דרך WPML → Languages
תוכן Placeholder — יש להסיר לפני השקה
  • /data-integration-quality/ — כותרות H2 "בלוק 2" ו"בלוק 3" — תוכן placeholder
  • /כל-המוצרים/ — שגיאת כתיב "prducts" בכותרת H2
  • לבצע סריקה מלאה של כל הדפים לאיתור Lorem Ipsum, כותרות placeholder ("סתם כותרת", "בלוק X") ותוכן זמני
  • דף בדיקה /בדיקה/ עדיין קיים — למחוק או לחסום מאינדוקס
Schema Markup — השלמות נדרשות
  • WebPage, BreadcrumbList, WebSite, Organization — קיימים בכל הדפים (תקין)
  • FAQPage schema חסר בדף /שאלות-ותשובות/ — נדרש לתוצאות מועשרות
  • Course schema חסר ב-21 דפי קורסים — נדרש לתוצאות מועשרות עם מחיר, משך, מיקום
  • להוסיף Review/AggregateRating schema בדף /המלצות/ — מאפשר כוכבים בתוצאות
  • להוסיף LocalBusiness schema בדף /צרו-קשר/ — כתובת, טלפון, שעות פעילות
  • Organization schema קיים אך חסר: description, sameAs, contactPoint, address
XML Sitemap
  • לוודא ש-Yoast SEO מייצר sitemap.xml תקין עם כל הדפים
  • לוודא שדפים שלא צריכים אינדוקס (דף בדיקה, thank-you pages) לא נכללים ב-sitemap
  • להגיש את ה-sitemap ל-Google Search Console מיד לאחר ההשקה
שדרוג PHP
  • האתר רץ על PHP 7.4 שהגיע לסוף תמיכה (EOL) — סיכון אבטחה ובעיות ביצועים
  • לשדרג ל-PHP 8.1+ לפני ההשקה — שיפור ביצועים משמעותי + תמיכה באבטחה
  • לבדוק תאימות תבניות ותוספים לפני שדרוג PHP
קישורים פנימיים
  • לבנות מבנה קישורים פנימי חזק: דף הבית → דפי מוצרים, דפי מוצרים → דפי קורסים, בלוג → דפי שירות
  • להוסיף "מאמרים קשורים" בתחתית כל פוסט בלוג — מקשר לדפים מסחריים רלוונטיים
  • להוסיף breadcrumbs ויזואליים (BreadcrumbList schema כבר קיים — לוודא שמופיע גם ב-UI)
מבנה URLs
  • ערבוב שפות ב-URLs: חלק באנגלית (/qlik-replicate/) וחלק בעברית (/אנליטיקה-מועצמת/) — לשקול אחידות
  • URLs בעברית עובדים אך מקודדים כ-percent-encoding בכלים מסוימים — שיקול UX
  • לוודא שכל ה-URLs מסתיימים ב-trailing slash באופן אחיד
Open Graph & Social Meta
  • להוסיף og:title, og:description, og:image לכל דף — משפר שיתוף ברשתות חברתיות
  • Yoast SEO תומך ב-OG tags — להגדיר בלשונית Social בכל עמוד
