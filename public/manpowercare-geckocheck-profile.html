Read first

  • Manpower Care is not in GeckoCheck yet. Section 01 is the list of what GeckoCheck staff should create. The account role is User with no setup screen, so send it to GeckoCheck support. The CSV files at the bottom are ready for a bulk import.
  • Never add מנפאואר or Manpower on their own as brand spellings. They are the parent company's name (manpower.co.il, ManpowerGroup Israel). The site shows up for מנפאואר but gets almost no clicks from it, which means those searchers want the parent company. Only the 6 spellings in section 02 count as Manpower Care.
  • נתיב 2 is registered as a brand term. It is Manpower Care's subsidiary for disabled IDF veterans (named on the site), so any query naming it is branded.
  • The core set is 50 queries (13 branded, 37 unbranded) across 7 categories and 5 service-line products. The full set adds 30 more for a larger plan.
  • Search volume is under-reported for Hebrew care terms. SE Ranking's Israeli database returns near-zero or no data for many care phrases that Search Console shows with hundreds of impressions (מטפלת סיעודית: 20 a month against 2,708 impressions in 90 days). Every keyword table shows both columns; read GSC impressions as the demand signal for this client.
  • Regulated topics are worded as open questions. Nursing benefit (גמלת סיעוד), dependency tests and foreign-worker permits are asked neutrally, with no entitlement, amount or legal outcome built into the question. Keep that rule for any query added later.
  • Queries write צהל without gershayim because quote marks break the import. That is also how people type it (מלווה לנכה צהל in Search Console).
