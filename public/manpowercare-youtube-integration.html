חלק 3 — איך משלבים סרטון בעמוד

3 גישות + best practices
גישה 1 — בלוק YouTube של WordPress (מומלץ)

האתר רץ על WordPress. הדרך הפשוטה היא לפתוח את העורך, להוסיף בלוק YouTube, ולהדביק את הקישור. WordPress מטפל אוטומטית ב-iframe, אחריות התאמת רוחב, וטעינה.

  • הבלוק נטען בעצלתיים (lazy loading) כברירת מחדל ב-WordPress 5.5+.
  • אם מותקן Yoast SEO, להפעיל את אפשרות "Use no-cookie domain" כדי להפחית עוגיות צד שלישי.
  • לכל בלוק להוסיף Caption (כיתוב) קצר עם 1-2 משפטים על הסרטון.
  • סרטון Hero או בראש מאמר: מומלץ Block Variation עם רוחב מלא (Wide / Full).
גישה 2 — iframe ידני עם רספונסיביות + lazy

כשמשלבים סרטון בתוך תבנית או דף מותאם, להשתמש בקוד הבא. עוטף יחס תצוגה 16:9, יוטיוב בדומיין ה-no-cookie, וטעינה עצלה. 

<!-- Responsive 16:9 wrapper -->
<div style="position:relative;padding-bottom:56.25%;height:0;overflow:hidden;border-radius:12px">
  <iframe
    src="https://www.youtube-nocookie.com/embed/VIDEO_ID?rel=0"
    title="כותרת בעברית של הסרטון"
    loading="lazy"
    frameborder="0"
    allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
    allowfullscreen
    style="position:absolute;top:0;left:0;width:100%;height:100%">
  </iframe>
</div>

להחליף VIDEO_ID במזהה הסרטון מהטבלה למעלה. דוגמה: dLzI9MUy9IY לסרטון 7.

גישה 3 — Facade (תמונה ממוזערת עם טעינה רק בלחיצה)

הסרטון נטען רק כשהמשתמש לוחץ על התמונה הממוזערת. עומס דף קל יותר, ניקוד Core Web Vitals גבוה יותר. מתאים לעמודי Hero או עמוד הבית. 

<!-- Click-to-load thumbnail (Lite YouTube Embed pattern) -->
<lite-youtube videoid="VIDEO_ID" style="background-image:url('https://i.ytimg.com/vi/VIDEO_ID/hqdefault.jpg')">
  <a href="https://youtube.com/watch?v=VIDEO_ID" class="lty-playbtn" title="נגן את הסרטון">
    <span class="lyt-visually-hidden">נגן</span>
  </a>
</lite-youtube>

דורש התקנת התוסף lite-youtube-embed (פתוח, חינמי). מומלץ לעמוד הבית של Manpower Care שכן יש שם 2-3 סרטונים ולא נרצה לטעון את כולם בו-זמנית.

Best Practices לשילוב בכל גישה
  • תמיד להשתמש ב-youtube-nocookie.com במקום youtube.com. פחות עוגיות, התאמה ל-GDPR.
  • תמיד להוסיף title ל-iframe עם כותרת ברורה בעברית. חיוני לנגישות ול-SEO.
  • תמיד להוסיף loading="lazy" אם יותר מ-1 סרטון בעמוד.
  • פסקת טקסט מעל הסרטון בעברית. גוגל מנתח את הקונטקסט סביב הסרטון לדירוג.
  • Caption (כיתוב) מתחת לסרטון עם 1-2 משפטים שמתארים מה רואים. עזרה ל-AI Search ולנגישות.
  • אל תפעילו autoplay. בנייד זה לא יעבוד, ובדסקטופ זה מרגיז.
  • פרמטר rel=0 בקישור Embed כדי שלא יוצגו סרטונים מערוצים אחרים בסוף.
  • פרמטר cc_lang_pref=he אם מופעלות כתוביות בעברית.
  • בדקו ב-Search Console אחרי השילוב שגוגל מזהה את הסרטון תחת Video indexing report.

חלק 4 — Schema לכל סרטון

VideoObject JSON-LD
למה זה חשוב

סכמת VideoObject מאפשרת לגוגל להציג Rich Result עם תמונה ממוזערת, אורך הסרטון, ותאריך העלאה בתוצאות החיפוש. בלי הסכמה הסרטון יופיע כקישור רגיל בלי גרפיקה. הסכמה גם חיונית ל-AI Search (ChatGPT, Perplexity, Gemini) לאיתור ולציטוט סרטונים מהאתר.

תבנית בסיס (להדביק עם החלפת ערכים)
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "VideoObject",
  "name": "כותרת הסרטון בעברית",
  "description": "תיאור של 50-150 תווים על תוכן הסרטון",
  "thumbnailUrl": [
    "https://i.ytimg.com/vi/VIDEO_ID/maxresdefault.jpg",
    "https://i.ytimg.com/vi/VIDEO_ID/hqdefault.jpg"
  ],
  "uploadDate": "YYYY-MM-DDTHH:MM:SS+03:00",
  "duration": "PT1M30S",
  "contentUrl": "https://www.youtube.com/watch?v=VIDEO_ID",
  "embedUrl": "https://www.youtube-nocookie.com/embed/VIDEO_ID",
  "inLanguage": "he-IL",
  "publisher": {
    "@type": "Organization",
    "name": "Manpower Care",
    "alternateName": "מנפאואר קר",
    "url": "https://manpowercare.co.il",
    "logo": {
      "@type": "ImageObject",
      "url": "https://manpowercare.co.il/wp-content/uploads/2024/08/Manpower-Care-Logo.png"
    }
  }
}
</script>

את הסכמה להניח בתוך <head> או לפני </body> של העמוד שבו הסרטון משולב. סרטון אחד = סכמה אחת ב-JSON-LD נפרד. אם מספר סרטונים באותו עמוד, להוסיף בלוק JSON-LD נפרד לכל אחד.

שדות חובה מול שדות מומלצים
שדה סטטוס הערה
nameחובהכותרת הסרטון בעברית, עד 110 תווים
descriptionחובהתיאור 50-150 תווים, עברית
thumbnailUrlחובה1280x720 פיקסל לפחות, רצוי maxresdefault.jpg של יוטיוב
uploadDateחובהפורמט ISO 8601: YYYY-MM-DDTHH:MM:SS+HH:MM
contentUrl או embedUrlחובהלפחות אחד מהשניים. רצוי שניהם
durationמומלץפורמט ISO 8601 Duration: PT1M30S (דקה ו-30 שניות)
publisherמומלץאובייקט Organization עם logo (≥112x112 פיקסל)
inLanguageמומלץhe-IL לעברית, ar לערבית, ru לרוסית
hasPartאופציונליאם רוצים פרקים (Clip / SeekToAction)
סכמות מוכנות ל-14 הסרטונים

14 סכמות, מוכנות להעתקה. רק להחליף את uploadDate בתאריך המדויק (הערוץ העלה את הסרטונים לפני 4-5 שנים, צריך תאריך מדויק לכל אחד) ולוודא ש-logo.url מצביע ללוגו האתר.
