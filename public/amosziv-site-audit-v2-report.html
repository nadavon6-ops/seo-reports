6 Cloudflare חוסם את כל הסורקים למעט גוגל עדיפות גבוהה
אתגר Cloudflare פעיל על כל האתר, כולל robots.txt
נבדק חי: כל בקשה לאתר, כולל /robots.txt ודף הבית, מחזירה HTTP 403 עם הכותרת cf-mitigated: challenge ודף ביניים. החסימה חלה גם על גרסת ה־www וגם על הדומיין הראשי. נבדקו ונחסמו: לקוח HTTP רגיל, דפדפן Chrome ללא ממשק, ו־Chrome אמיתי המופעל אוטומטית. רק גלישה אנושית אמיתית עוברת.
מנגד, גוגל כן עוברת: בדיקת הכתובות ב־Search Console מראה סריקה אחרונה מוצלחת ומצב "נוספה לאינדקס". כלומר גוגל אינה חסומה כרגע. הבעיה היא שכל שאר הסורקים כן, ובכללם סורקי מנועי ה־AI, בדיוק המחלקה שאתגר מנוהל חוסם כברירת מחדל. הדבר מתיישב עם שלוש הכניסות בלבד ממנועי AI ברבעון.
לביצוע: לבקש מספק האחסון להוסיף כלל דילוג ב־WAF עבור סורקים מאומתים, כולל GPTBot, PerplexityBot, ClaudeBot ו־Bingbot, ולוודא ש־/robots.txt מוגש תמיד ללא אתגר. יש לוודא זאת מול יומן Security Events בחשבון Cloudflare, שאינו נגיש לנו כרגע.
