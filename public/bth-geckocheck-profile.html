Read first

  • Bituach Haklai is not in GeckoCheck yet. Section 01 is the list of what to create. The account role is User and the app has no setup screen, so send it to GeckoCheck support. The CSV files at the bottom are ready for a bulk import.
  • The brand name is also a generic Hebrew phrase. ביטוח חקלאי literally means agricultural insurance. In the search data it behaves as the brand: the homepage ranks first for it, and the generic phrasings (ביטוח לחקלאים, ביטוח חקלאות, ביטוח משק חקלאי) show 0 searches a month in SE Ranking. So every query containing ביטוח חקלאי is classed as branded, and the unbranded farm questions are worded without it. In answers, the same phrase can appear in its generic sense (for example about קנט, the fund for agricultural natural-disaster insurance). Spot-check brand mentions in the Kibbutz and agriculture category after the first period.
  • No Search Console access for bth.co.il. The demand behind each query comes from SE Ranking (tracked keywords and the Data API, Israel) and Ahrefs (Israel). The GSC columns are empty for that reason, not because the terms have no impressions.
  • Insurance is regulated. Queries ask; they never state a price, a discount or a coverage as a fact. Keep it that way when editing.
  • Every target page was fetched on 24.09.2026 and returns a real page. Several sitemap entries on bth.co.il serve an error page with status 200 or redirect, so none of those are used.
  • The core set is 50 queries (17 branded, 33 unbranded). The full set adds 35 more for a larger plan.
  • Never add משקארד or מנורה as brand spellings. Meshekard is a separate consumer club promoted on the BTH homepage; Menora is a competitor that took over BTH's life-insurance book in 2020.
