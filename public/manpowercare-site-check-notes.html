אין תגית Canonical באף עמוד באתר

חוסם השקה

נבדקו כל 129 הכתובות שבמפות האתר (128 עמודי תוכן ועוד רשומה טכנית אחת של Elementor). באף אחת מהן אין תגית rel="canonical".

תגית Canonical מציינת לגוגל מהי הכתובת הרשמית של העמוד. בלעדיה, כל וריאציה של כתובת (עם או בלי סלאש בסוף, עם פרמטרים, באותיות גדולות) עלולה להיספר כעמוד נפרד. באתר שבו קיימים עמודים דומים, הדבר מגדיל את הסיכון שגוגל יבחר גרסה שאינה המועדפת עלינו.

Yoast SEO מפיק תגית Canonical עצמית לכל עמוד כברירת מחדל, ולכן כדאי לברר תחילה מדוע היא אינה מופיעה.

הפעולה הנדרשת: לבדוק את הגדרות Yoast לפי הסדר שלמטה. אם Yoast אינו בשימוש, להוסיף את הקוד הידני לעמודים בודדים בלבד.
בדיקת המקור, לפי הסדר
Yoast SEO גרסה 28.1 מותקן ופעיל באתר, ובכל זאת התגית אינה מופיעה.
לכן מדובר בסינון של הפלט, ולא בהיעדר התוסף. לבדוק לפי הסדר:

1. חפשו בקוד התבנית ובתוספים את הפילטר:
   wpseo_canonical
   אם מוחזר false או מחרוזת ריקה, Yoast אינו מדפיס את התגית.

2. בדקו אם קיים תוסף cache או optimization שמסיר תגיות מה-head.

3. בדקו בתבנית הבת (hello-theme-child-master) קוד שמסיר פעולות מ-wp_head.

לאיתור הפילטר, הריצו זמנית:

add_action('wp_head', function () {
    echo '<!-- yoast canonical: ' . esc_html(
        apply_filters('wpseo_canonical', 'NOT-FILTERED')
    ) . ' -->';
}, 999);

אם הפלט אינו NOT-FILTERED, מישהו מסנן את התגית.

אין להוסיף תגית canonical ידנית כל עוד Yoast פעיל,
כדי לא ליצור שתי תגיות canonical באותו עמוד.

ארבעה פוסטים בבלוג נושאים שתי תגיות תיאור מטא

חוסם השקה

ההערה שהתקבלה מהצוות נבדקה ואומתה. בארבעה פוסטים קיימות שתי תגיות meta name="description" באותו עמוד.

העמודתגית 1, של Yoast (מקוצר)תגית 2, של התבנית (מקוצר)
/כשהגוף-מאותת-כדאי-לעצור/מהם הסימנים לסיבוכי סוכרת ואיך מונעים החמרה...הקשבה ותשומת לב לשינויים החלים בגוף...
/רגעים-קטנים-של-חסד-60-דברים.../60 משחקים ופעילויות לחולי דמנציה ואלצהיימר...רוצים לעשות טוב? הנה כמה רעיונות שעובדים נהדר.
/על-השיטות-והכלים-השונים.../כיצד פעילות גופנית, תנועה וריקוד מסייעים...כתבה שלישית בסדרה: טיפול באמצעות תנועה
/טיפול-פליאטיבי-וליווי-סוף-חיים-בבית/טיפול פליאטיבי וליווי סוף חיים בבית, הכולל...כשאדם יקר לכם מתמודד עם מחלה קשה או מתקדמת...

מקור הבעיה, כפי שאותר: התגית הראשונה נמצאת בתוך בלוק Yoast בראש העמוד (מיקום 445 בקוד) והיא התגית הממוטבת. התגית השנייה מופיעה הרבה יותר למטה (מיקום 24,000 ומעלה), מחוץ לבלוק Yoast, והתוכן שלה זהה לתקציר הפוסט (excerpt).

התבנית המותקנת באתר היא Hello Elementor (עם תבנית בת hello-theme-child-master). לתבנית זו יש מנגנון שמדפיס את תקציר הפוסט כתיאור מטא, והוא פועל במקביל ל-Yoast.

כשיש שתי תגיות, גוגל בוחר אחת מהן בעצמו, ולעיתים יבחר דווקא את התקציר הקצר והלא ממוטב.

הטקסטים בטבלה מוצגים מקוצרים לצורך תצוגה. נבדקו כל 129 הכתובות באתר, ואלה ארבעת המקרים היחידים. בשאר העמודים יש תגית אחת או אף אחת.

הפעולה הנדרשת: להסיר את פלט תיאור המטא של התבנית ולהשאיר את זה של Yoast בלבד. הקוד שלמטה מסיר את הפלט הכפול מבלי לגעת ב-Yoast.
אפשרות א, מומלצת: כיבוי דרך הגדרות התבנית
Hello Elementor כולל הגדרה לכיבוי תגית התיאור.

WordPress Admin > Appearance > Hello Elementor Settings
ובתוכה החלק של Head, סמנו כיבוי של
Description meta tag / Disable description meta tag

זו הדרך הבטוחה ביותר, ואינה דורשת קוד.
אפשרות ב: ניתוק דרך functions.php של תבנית הבת
// לוודא תחילה את שם ה-callback המדויק בגרסת התבנית המותקנת.
// בגרסאות Hello Elementor הנפוצות זהו:

remove_action('wp_head', 'hello_elementor_add_description_meta_tag');

// לאימות שם ה-callback, הריצו זמנית בעמוד פוסט:

add_action('wp_head', function () {
    global $wp_filter;
    if (empty($wp_filter['wp_head'])) { return; }
    foreach ($wp_filter['wp_head']->callbacks as $prio => $cbs) {
        foreach ($cbs as $id => $cb) {
            echo "\n<!-- wp_head $prio : $id -->";
        }
    }
}, 999);

// חפשו בפלט שם שמכיל description, והשתמשו בו ב-remove_action.
// שימו לב: אם ה-callback הוא מתודה של מחלקה או פונקציה אנונימית,
// remove_action עם שם פשוט לא יעבוד, ויש לפנות לאפשרות א.

תיקון להערה קודמת: בדוח קודם צוין שיש להשלים תיאורי מטא ל-65 עמודי מנהלי הסניפים. הדבר אינו נדרש. העמודים הם כפילויות של אותו אדם בשפות שונות, והפתרון הנכון הוא noindex ואיחוד, ולא כתיבת תיאורים לכל אחד מהם.

תחת /branchmanager/ קיימות 65 כתובות, ועוד 2 תחת /author/. מנהלים רבים מופיעים בכמה כתובות בשפות שונות (עברית, אנגלית, רוסית וערבית), ולתשעה מהם קיים גם עמוד נוסף עם הסיומת "-2". לרנה דנילוב, לדוגמה, קיימות חמש כתובות פעילות.

הפעולה הנדרשת: להשאיר עמוד אחד לכל מנהל.ת ולתת noindex לשאר, וכן לעמודי /author/. אין צורך בתיאורי מטא לעמודים אלה.
functions.php: noindex לעמודי הכפילות
// שלב 1: לאשר מול החברה איזה עמוד מכל זוג הוא העדכני.
// שלב 2: להוסיף כאן רק את ה-slugs שיוצאים משימוש.

add_filter('wpseo_robots_array', function ($robots) {
    // הרשימה ריקה בכוונה. יש למלא אותה רק לאחר
    // שהחברה אישרה איזה עמוד מכל זוג הוא העדכני.
    $retire = [
        // 'רנה-דנילוב-2',
        // 'נאהלה-מלחם-2',
    ];
    if (is_singular('branchmanager') && in_array(get_post_field('post_name'), $retire, true)) {
        $robots['index'] = 'noindex';
    }
    if (is_author()) {
        $robots['index'] = 'noindex';
    }
    return $robots;
});

// wpseo_robots_array הוא הפילטר הנוכחי ב-Yoast 14 ומעלה.

עמודי קטגוריה: noindex, follow ולא הפניה

מבנה

קטגוריה בוורדפרס היא טקסונומיה פעילה, והפניית 301 עליה שוברת את מבנה הניווט של הבלוג. ההמלצה היא noindex, follow, שמוציא את הארכיון הדל מהחיפוש ושומר על תפקוד הניווט ועל מעבר הערך בקישורים.

משתמשים בהפניה 301 רק אם מוחקים קטגוריה לחלוטין ויש לה קישורים או תנועה נכנסת.

הפעולה הנדרשת: להגדיר את עמודי הקטגוריה כ-noindex, follow עם העלייה לאוויר.
