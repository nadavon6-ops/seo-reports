אין תגית Canonical באף עמוד באתר

חוסם השקה

נבדקו כל 128 הכתובות שבמפות האתר. באף אחת מהן אין תגית rel="canonical".

תגית Canonical מציינת לגוגל מהי הכתובת הרשמית של העמוד. בלעדיה, כל וריאציה של כתובת (עם או בלי סלאש בסוף, עם פרמטרים, באותיות גדולות) עלולה להיספר כעמוד נפרד. באתר שבו קיימים עמודים דומים, הדבר מגדיל את הסיכון שגוגל יבחר גרסה שאינה המועדפת עלינו.

Yoast SEO מפיק תגית Canonical עצמית לכל עמוד כברירת מחדל, ולכן כדאי לברר תחילה מדוע היא אינה מופיעה.

הפעולה הנדרשת: לבדוק את הגדרות Yoast לפי הסדר שלמטה. אם Yoast אינו בשימוש, להוסיף את הקוד הידני לעמודים בודדים בלבד.
בדיקת המקור ב-Yoast, לפי הסדר
1. ודאו ש-Yoast SEO פעיל ומעודכן (בבדיקה: גרסה 28.1 מותקנת).
2. Yoast > Settings > Site features: ודאו ש-Crawl optimization אינו מסיר את התגית.
3. Yoast > Advanced > Crawl settings: ודאו שלא הוגדרה הסרת canonical.
4. בדקו שאין תוסף או קוד בתבנית שמסנן את הפלט של Yoast.

עדיף לתקן את המקור מאשר להוסיף תגית ידנית, שעלולה
להתנגש עם Yoast וליצור שתי תגיות canonical באותו עמוד.
רק אם Yoast אינו בשימוש: קוד לעמודים בודדים
add_action('wp_head', function () {
    if (!is_singular()) { return; }
    if (function_exists('YoastSEO')) { return; }
    $url = wp_get_canonical_url();
    if ($url) {
        echo '<link rel="canonical" href="' . esc_url($url) . '" />' . "\n";
    }
});

65 עמודי מנהלי סניפים, כפילות בין שפות

כפילות
תיקון להערה קודמת: בדוח קודם צוין שיש להשלים תיאורי מטא ל-65 עמודי מנהלי הסניפים. הדבר אינו נדרש. העמודים הם כפילויות של אותו אדם בשפות שונות, והפתרון הנכון הוא noindex ואיחוד, ולא כתיבת תיאורים לכל אחד מהם.

תחת /branchmanager/ קיימות 65 כתובות, ועוד 2 תחת /author/. מנהלים רבים מופיעים בכמה כתובות בשפות שונות, ולתשעה מהם קיים גם עמוד נוסף עם הסיומת "-2".

שני העמודים בעברית נושאים כותרת ראשית זהה אך משייכים את אותה מנהלת לשני סניפים שונים, עם כתובות מייל שונות. נדרש לאשר מול החברה איזה שיוך עדכני.

הפעולה הנדרשת: להשאיר עמוד אחד לכל מנהל.ת ולתת noindex לשאר, וכן לעמודי /author/. אין צורך בתיאורי מטא לעמודים אלה.
functions.php: noindex לעמודי הכפילות
// שלב 1: לאשר מול החברה איזה עמוד מכל זוג הוא העדכני.
// שלב 2: להוסיף כאן רק את ה-slugs שיוצאים משימוש.

add_filter('wpseo_robots_array', function ($robots) {
    $retire = [
        'רנה-דנילוב-2',
        'נאהלה-מלחם-2',
        'meital-hilve-kimmel-2',
        'marina-gershengoren-2',
        // להשלים לפי ההחלטה
    ];
    if (is_singular('branchmanager') && in_array(get_post_field('post_name'), $retire, true)) {
        $robots['index'] = 'noindex';
    }
    if (is_author()) {
        $robots['index'] = 'noindex';
    }
    return $robots;
});

// wpseo_robots_array הוא הפילטר הנוכחי ב-Yoast 14 ומעלה.
