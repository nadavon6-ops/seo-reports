כל עמודי המשרות (/job/*) חסרים תיאור מטא לחלוטין.
שדה metaDesc ב-Yoast/WPGraphQL מחזיר מחרוזת ריקה ("") → Next.js לא מרנדר תגית <meta name="description"> → גוגל מייצר snippet אוטומטי מתוכן העמוד → אובדן 15-30% מה-CTR.

2 פורמט דינמי נדרש
דרוש/ה [JOB_TITLE] – משרה ב[LOCATION] | מנפאואר ישראל. הגישו מועמדות עכשיו.
שדה מקור הנתון דוגמה סטטוס
[JOB_TITLE] pageProps.job.title מנהל/ת חשבונות חובה
[LOCATION] pageProps.job.jobAreas (ערך ראשון) השפלה חובה — עם fallback
הגבלת תווים: תיאור מטא חייב להיות עד 155 תווים. הפורמט הבסיסי (ללא ערכים דינמיים) תופס ~50 תווים, כך שנותר מקום רחב לכותרות ומיקומים.
3 מקור הנתונים — מבנה __NEXT_DATA__
כל נתוני המשרה כבר זמינים ב-pageProps.job שמגיע מה-SSR. אין צורך בקריאת API נוספת.
מבנה הנתונים הרלוונטי (מתוך pageProps.job):
pageProps.job = { code: "236844", // מזהה משרה title: "מנהל/ת חשבונות", // ← JOB_TITLE ★ jobAreas: "השפלה", // ← LOCATION (אזור) ★ scope: "משרה מלאה", // היקף משרה domain: "פיננסים וכספים", // תחום מקצועי subProfession:"מנהח״ש", // תת-תחום experience: "נדרש ניסיון", // דרישת ניסיון description: "<p>חברה במודיעין...</p>" // תיאור HTML }
שימו לב: שדה jobAreas מכיל את האזור (למשל "השפלה", "מרכז", "תל אביב"). זהו השדה שממופה ל-[LOCATION] בתיאור הדינמי.
4 מימוש — קוד
המימוש מתבצע בקומפוננטת עמוד המשרה (/job/[slug]). יש להוסיף את הלוגיקה שמייצרת את התיאור הדינמי ומזריקה אותו לתגית <Head>.
שלב 1: פונקציית יצירת התיאור הדינמי
/** * Generate dynamic meta description for job pages. * Format: "דרוש/ה [TITLE] – משרה ב[LOCATION] | מנפאואר ישראל. הגישו מועמדות עכשיו." * Max length: 155 characters. */ function generateJobMetaDescription(job) { const title = job.title || ''; const location = job.jobAreas || ''; if (!title) { // Fallback: no title available return 'משרות חדשות במנפאואר ישראל. הגישו מועמדות עכשיו.'; } if (!location) { // Fallback: title exists but no location return `דרוש/ה ${title} | מנפאואר ישראל. הגישו מועמדות עכשיו.`; } // Full format const desc = `דרוש/ה ${title} – משרה ב${location} | מנפאואר ישראל. הגישו מועמדות עכשיו.`; // Truncate if over 155 characters if (desc.length > 155) { return `דרוש/ה ${title} – ${location} | מנפאואר ישראל. הגישו מועמדות עכשיו.`; } return desc; }
שלב 2: הזרקה ל-Head בקומפוננטת העמוד
// In: pages/job/[slug].js (or .tsx) import Head from 'next/head'; export default function JobPage({ job }) { const metaDescription = generateJobMetaDescription(job); return ( <> <Head> <meta name="description" content={metaDescription} /> <meta property="og:description" content={metaDescription} /> </Head> {/* ... rest of page content ... */} </> ); }
שימו לב: מכיוון שהנתונים כבר מגיעים ב-SSR (דרך getServerSideProps / getStaticProps), התיאור הדינמי יהיה בתוך ה-HTML הראשוני שגוגל מקבל — ללא צורך ב-JavaScript בצד הלקוח.

7 היכן בקוד — מיקום הקובץ
קובץ פעולה
pages/job/[slug].js
(או .tsx אם TypeScript)		 להוסיף:
1. פונקציית generateJobMetaDescription(job)
2. תגית <meta name="description"> בתוך <Head>
3. תגית <meta property="og:description"> בתוך <Head>
חלופה — מימוש ב-SSR: אם עדיף ליצור את ה-description בצד השרת, ניתן להוסיף את הלוגיקה ישירות ב-getServerSideProps / getStaticProps ולהעביר את התיאור כ-prop נוסף:
חלופה: יצירה ב-getServerSideProps
export async function getServerSideProps({ params }) { const job = await fetchJob(params.slug); return { props: { job, metaDescription: generateJobMetaDescription(job), }, }; }
8 בדיקת תקינות (QA)
לאחר המימוש, יש לבדוק את הנקודות הבאות:
  • פתיחת View Source בדפדפן → חיפוש <meta name="description" → וידוא שהתגית קיימת ומכילה טקסט דינמי
  • בדיקה שהתיאור מתחיל ב-"דרוש/ה"
  • בדיקה שכותרת המשרה (job.title) מופיעה בתיאור
  • בדיקה שהמיקום (job.jobAreas) מופיע כשזמין
  • בדיקת fallback — משרה ללא מיקום → תיאור ללא אזור (אבל עדיין תקין)
  • אורך תיאור ≤ 155 תווים
  • וידוא שגם og:description מעודכן (לשיתוף ברשתות חברתיות)
  • בדיקה ב-Google Rich Results Test שהתיאור נקרא
בדיקה מהירה בדפדפן (DevTools Console):
