1 תיקון שפת סכמה ל-he-IL בכל העמודים
מאמץ: קטן 7 ימים

הבעיה

כל סכמות ה-JSON-LD באתר מכילות "inLanguage": "en-US" למרות שהתוכן בעברית.

זה מבלבל את Google בהבנת קהל היעד ופוגע בדירוג בחיפושים בעברית.

היכן נמצא

סכמת WebSite: "@type": "WebSite" → מכילה "inLanguage": "en-US"

סכמת WebPage: "@type": "WebPage" → מכילה "inLanguage": "en-US"

היקף: כל העמודים באתר (דף הבית, דגמים, בלוג, שירות)

מה לשנות

בכל סכמת JSON-LD באתר, להחליף:

// לפני (שגוי): "inLanguage": "en-US" // אחרי (נכון): "inLanguage": "he-IL"

איפה לשנות (WordPress/Yoast)

  1. בדקו ב-Settings → General → Site Language - צריך להיות "עברית"
  2. אם שפת האתר כבר עברית ועדיין en-US בסכמה → בדקו ב-Yoast SEO → Search Appearance → General
  3. אם Yoast לא מאפשר שינוי → הוסיפו filter ב-functions.php:
// functions.php - Fix Yoast schema language add_filter( 'wpseo_schema_webpage', function( $data ) { $data['inLanguage'] = 'he-IL'; return $data; }); add_filter( 'wpseo_schema_website', function( $data ) { $data['inLanguage'] = 'he-IL'; return $data; });

בדיקת תקינות

  • פתחו את קוד המקור של דף הבית → חפשו "inLanguage" → ודאו שכתוב "he-IL"
  • בדקו בעמוד דגם (למשל /models/tiggo8pro-phev/) → אותה בדיקה
  • בדקו ב-Rich Results Test של Google

הנחיות חשובות

שימו לב:
  • כל מיקום צריך בלוק JSON-LD נפרד - לא לשים הכל באובייקט אחד
  • קואורדינטות (latitude/longitude) - חובה למלא מ-Google Maps
  • שעות פתיחה - למלא לפי הנתונים המופיעים באתר לכל סניף
  • אם לסניפים יש עמודים ייעודיים - לשנות את ה-url לעמוד הספציפי

4 פיתוח מודול ביקורות משתמשים
מאמץ: גבוה 90 יום

הבעיה

באתר אין מנגנון ביקורות משתמשים. מתחרים כמו auto.co.il מציגים דירוג 4.8/5 מביקורות בעלי רכב.

ביקורות משתמשים מחזקות E-E-A-T (Experience), יוצרות תוכן ייחודי ומתעדכן, ומאפשרות הצגת כוכבים ב-SERP.

דרישות פונקציונליות

  1. דירוג כוכבים: 1-5 כוכבים בקטגוריות: חוויית נהיגה, נוחות, תמורה למחיר, בטיחות, עלויות אחזקה
  2. טקסט חופשי: שדה טקסט (200-2000 תווים) לתיאור החוויה
  3. פרטי כותב: שם (חובה) + אימייל (חובה, לא מוצג) + דגם רכב (חובה)
  4. אימות: אימות אימייל לפני פרסום למניעת ספאם
  5. מודרציה: ביקורות עוברות אישור לפני פרסום
  6. תצוגה: אזור ביקורות בתחתית כל עמוד דגם, עם ציון ממוצע מוצג

מיקום במבנה העמוד

איפה: כל 11 עמודי הדגמים תחת /models/

מיקום בעמוד: לפני סקשן "שאלות נפוצות" ואחרי מפרט טכני

מבנה: ציון ממוצע למעלה → רשימת ביקורות → טופס הוספת ביקורת

הנחיות חשובות

שימו לב:
  • אל תציגו AggregateRating בסכמה עד שיש לפחות 3 ביקורות אמיתיות
  • אימות אימייל הכרחי למניעת ביקורות מזויפות
  • מומלץ תוסף WordPress כמו WP Customer Reviews או Site Reviews
  • לוודא שה-schema מתעדכן אוטומטית כשנוספות ביקורות

בדיקת תקינות

  • בדקו שטופס הביקורת עובד (שליחה + אימות אימייל)
  • בדקו שהביקורת מופיעה לאחר אישור
  • ודאו שהציון הממוצע מחושב נכון
  • בדקו ב-Rich Results Test שה-AggregateRating מופיע
  • בדקו שאין פגיעה בביצועי טעינת העמוד
