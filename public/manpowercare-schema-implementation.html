הטמעת סכמות באתר החדש, מדריך למפתח

שלושה כללים להטמעה:
  • Yoast כבר מפיק Organization, WebSite, BreadcrumbList ו-WebPage בכל עמוד, ו-Article עם Person בכל פוסט. אין להוסיף בלוקים מהסוגים האלה ידנית, זו כפילות.
  • כל הקוד כתוב עם כתובות הדומיין manpowercare.co.il, נכון למצב שאחרי ההחלפה.
  • מקום ההדבקה: WPCode או Custom Code של אלמנטור, מיקום Head, עם תנאי הצגה לעמוד הרלוונטי.

סעיף 1, Organization

פעם אחת, לכל האתר
1

העברת נתוני ה-Organization מהאתר הקיים: כתובת, טלפונים ופרופילים חברתיים

עדיפות ראשונה

הנתונים האלה קיימים היום בסכמה של האתר הישן ועוברים לאתר החדש בשני צעדים. חשוב: לא מדביקים בלוק Organization נפרד (כמו שקיים באתר הישן), אלא מעשירים את הבלוק שהאתר כבר מפיק. בלוק נפרד ייצור שתי ישויות Organization מתחרות.

צעד א, בהגדרות Yoast (Settings, Site representation): שם הארגון Manpower Care, שם חלופי מנפאואר קר, ולוגו: קובץ הלוגו הראשי בגודל 112 פיקסלים לפחות. זה גם מתקן את השם הנוכחי בסכמה, שהוא כרגע שם האתר מההתקנה.

צעד ב, קטע PHP שמוסיף כתובת, דרכי התקשרות ופרופילים חברתיים:

PHP, מסנן wpseo_schema_organization
// להוסיף ל-functions.php של תבנית הבן, או דרך תוסף קטעי קוד (WPCode)
add_filter( 'wpseo_schema_organization', function( $data ) {

    $data['address'] = array(
        '@type'           => 'PostalAddress',
        'streetAddress'   => 'התע"ש 23',
        'addressLocality' => 'כפר סבא',
        'addressCountry'  => 'IL',
    );

    $data['contactPoint'] = array(
        array(
            '@type'             => 'ContactPoint',
            'telephone'         => '*9055',
            'contactType'       => 'customer service',
            'areaServed'        => 'IL',
            'availableLanguage' => array( 'he', 'en' ),
        ),
        array(
            '@type'       => 'ContactPoint',
            'telephone'   => '03-5496311',
            'contactType' => 'head office',
            'areaServed'  => 'IL',
        ),
        array(
            '@type'       => 'ContactPoint',
            'telephone'   => '03-5404566',
            'contactType' => 'fax',
            'areaServed'  => 'IL',
        ),
    );

    $data['sameAs'] = array(
        'https://www.facebook.com/ManpowerCare/',
        'https://www.youtube.com/@manpowercare-6429',
    );

    return $data;
} );
היכן להדביק: קובץ functions.php של תבנית הבן, או תוסף WPCode בקטע מסוג PHP Snippet במיקום Run Everywhere. לא בהדר, לא בפוטר ולא בגוף העמוד.

בלוק Service לחמשת עמודי השירות המרכזיים

עדיפות שנייה

סכמת Service מגדירה לגוגל ולמנועי הבינה המלאכותית את השירותים עצמם, מקושרים לישות החברה. כל בלוק מודבק בעמוד שלו בלבד.

סכמת Person קיימת בכל המאמרים, אבל שם הכותב הוא שם משתמש טכני

תיקון בהגדרות

סכמת Person מופקת אוטומטית בכל מאמר כישות הכותב, מקושרת לסכמת ה-Article (סעיף 4). אין צורך להדביק קוד. הבעיה: ב-20 מתוך 23 המאמרים שם הכותב בסכמה הוא שם המשתמש הטכני manpowerus26, וגוגל ומנועי הבינה המלאכותית קוראים אותו כזהות הכותב של התוכן.

כך זה נראה היום בסכמה של המאמרים:

המצב היום (לתיקון)
{
  "@type": "Person",
  "name": "manpowerus26"
}
היכן להדביק: אין קוד להדבקה בסעיף זה, לא בהדר, לא בפוטר ולא בגוף העמוד.
הפעולה הנדרשת: בוורדפרס, במסך Users, לפתוח את המשתמש שכתב את המאמרים, למלא שם תצוגה מקצועי (למשל צוות מנפאואר קר) ולבחור אותו בשדה Display name publicly as. הסכמה מתעדכנת באופן אוטומטי בכל המאמרים. אותו תיקון רלוונטי גם לשם Gal Hadad בשלושת המאמרים הנותרים, אם מעדיפים שם כותב אחיד.

סעיף 8, מה לא מעבירים ומה מסירים

שלושה בלוקים ישנים שנשארים מאחור ותיקון אחד בסכמה הקיימת
8

שלושה בלוקים מהאתר הישן שאין להעביר, והסרת סימון חיפוש שאינו קיים

חשוב
בלוק באתר הישןלמה לא מעבירים
בלוק Organization נפרד שמופיע בכל עמודי האתר הישןבאתר החדש הנתונים נכנסים לתוך הבלוק הקיים דרך סעיף 1. העתקה של הבלוק הנפרד תיצור שתי ישויות Organization בכל עמוד.
BreadcrumbList ידני בעמוד תביעה לגמלת סיעודהאתר החדש מפיק Breadcrumb אוטומטית בכל עמוד (סעיף 5). בלוק ידני נוסף יוצר כפילות.
בלוק FAQPage בעמוד תביעה לגמלת סיעודהבלוק הישן מכיל שגיאת תחביר (JSON לא תקין) ונוסח ישן. במקומו נבנה בלוק חדש ותקין בסעיף 3, מהנוסח של העמוד החדש.

הסרה אחת בסכמה הקיימת: הסכמה מצהירה בכל עמוד על פעולת חיפוש (SearchAction) באתר, אבל באתר אין תיבת חיפוש. שורה אחת מסירה את ההצהרה:

add_filter( 'disable_wpseo_json_ld_search', '__return_true' );
