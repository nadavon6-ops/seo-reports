Is the SEO Being Done Correctly?

Verdict: SEO is Partially Implemented — Major Gaps Remain

The site has basic SEO infrastructure (Yoast SEO, sitemaps, HTTPS) and ranks well for branded terms. However, fundamental on-page optimization is incomplete: 18 core pages lack meta descriptions, titles are generic, keyword targeting is unfocused, and severe cannibalization is splitting ranking signals across multiple URLs.

SEO Scorecard

Title Tags
40%

Generic pattern "[Page] - Makoa a Boutique Style Maui Resort" wastes 38 chars on site name. Property pages use generic names (Villa 1, Villa 2) with no keyword targeting.

Meta Descriptions
25%

Only homepage and /accommodation/ property pages have descriptions. 18 core pages (accommodations, weddings, activities, FAQ, etc.) have none.

H1 Structure
30%

Property pages have 3 H1 tags each (HomeRunner template bug). /amenities/ page has lowercase "amenities" as H1. Taxonomy pages reuse homepage H1.

Keyword Targeting
35%

No deliberate keyword-to-page mapping. Homepage targets everything. High-value terms like "maui vacation rentals" (1,300 vol) have no dedicated page.

Content Depth
30%

No blog. No informational content. No location guides. No activity articles. Zero informational keyword coverage.

Internal Linking
45%

Navigation links to main pages. But no cross-linking between properties, no contextual links from content to property pages, potential orphan pages.

Schema / Structured Data
20%

Only Yoast defaults (WebPage, Organization, BreadcrumbList). Missing LodgingBusiness, VacationRental, FAQPage, Event, Review — critical for a resort website.

Index Health
25%

155 URLs in sitemap, ~100 should be noindexed (94 amenity taxonomies, utility pages, search pages). Duplicate content at multiple URLs.

Technical SEO Issues

Platform: WordPress 6.9.1 + Elementor 3.35.6 + Yoast SEO 27.1.1 + HomeRunner 2.1.3

CRITICAL 94 Thin Amenity Taxonomy Pages Indexed

All /property-amenity/ pages (swimming-pool, microwave, air-conditioning, etc.) are in the sitemap and set to index. Each reuses the homepage title, meta description, and H1 — creating 94 pages of duplicate content.

Fix: Yoast SEO > Search Appearance > Taxonomies > Property Amenities > set to "No" (noindex). Remove from sitemap.

CRITICAL 18 Core Pages Missing Meta Descriptions

/accommodations/, /amenities/, /activities/, /location/, /faq/, /weddings/, /events/, /wellness-retreats/, /concierge/, /contact/, /wailea-inn/, /villas-by-the-cove/, /beach-front-villas/, /villas-1-9/, /reservation-policy/, /reservation-policy-2/, and all search pages have no meta descriptions.

Fix: Write unique, keyword-rich meta descriptions (120-155 chars) for each page in Yoast. Prioritize by traffic potential.

CRITICAL Utility & Search Pages Indexed

/checkout/, /confirmation/, /guest-dashboard/, /search-results/, /search-villa/, /search-waileainn/, /search-penthouse/ are all indexable and in the sitemap. These have zero SEO value and create index bloat.

Fix: Set all to noindex via Yoast and remove from sitemap.

CRITICAL Taxonomy Pages Have Duplicate Homepage Metadata

/property-type/, /property-state/hawaii/, /property-city/kihei/, /property-flag/ all display the homepage title, description, and H1. 7 pages with identical metadata to the homepage.

Fix: Noindex these taxonomies in Yoast, or write unique titles/descriptions for each.

HIGH Duplicate Content — Properties at Multiple URLs

/garden-hideaway/ and /accommodation/garden-hideaway/ both exist and self-canonicalize. Same for /oceanfront-hideaway/ and /villas-1-9/. Both versions are in the sitemap.

Fix: 301 redirect the /page/ versions to the /accommodation/ versions. Remove redirected URLs from sitemap.

HIGH Duplicate Reservation Policy Pages

/reservation-policy/ and /reservation-policy-2/ have the same title. Navigation links to the "-2" version. Both are in the sitemap.

Fix: 301 redirect /reservation-policy/ to /reservation-policy-2/.

HIGH Multiple H1 Tags on Property Pages

Every /accommodation/ page has 3 H1 tags (desktop name, mobile name, "Amenities" heading). HomeRunner template generates this structure by default.

Fix: Edit HomeRunner template — change amenities heading to H2, consolidate property name H1s using CSS responsive display.

HIGH No Industry-Specific Schema Markup

Only Yoast default schemas (WebPage, Organization, BreadcrumbList). Missing LodgingBusiness, VacationRental, FAQPage, Event — critical for a resort site's rich result eligibility.

Fix: Implement JSON-LD for LodgingBusiness (homepage), VacationRental (property pages), FAQPage (/faq/), Event (/weddings/, /events/).

HIGH Zero Security Headers

No HSTS, X-Frame-Options, X-Content-Type-Options, Content-Security-Policy, or Referrer-Policy headers. While not a direct ranking factor, Google considers site security a trust signal.

Fix: Add security headers via .htaccess or server configuration.

MEDIUM Excessive CSS/JS Files (40 CSS + 41 JS)

Homepage loads 81 combined CSS and JavaScript files. 3 separate Google Fonts loaded with ALL weight variants. This impacts Core Web Vitals (LCP, INP).

Fix: Enable Elementor performance settings. Install caching/optimization plugin. Self-host fonts, load only needed weights.

MEDIUM Non-SEO-Friendly Property URLs

Some properties use numeric IDs (/404589/, /803708/, /490021/) instead of descriptive slugs. These URLs rank for keywords like "hawaii plantation home" and "kihei villa" but aren't optimized.

Fix: If URL migration is feasible, create descriptive slugs with proper 301 redirects. If not, ensure internal links use the descriptive page versions.

Index Bloat Summary

155 URLs in sitemap. Approximately 100+ should be noindexed (94 amenities + 7 utility/search pages + duplicates). Effective site is only ~50 unique, valuable pages. Cleaning this up will immediately improve crawl efficiency and consolidate ranking signals.
