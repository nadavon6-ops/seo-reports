#17 Canonical Tags - CRITICAL BUG Critical
Scope: Sitewide (all pages)
Current State: Canonical tags EXIST but are BROKEN
The Bug: All canonical tags show href="undefined/..."
Evidence from HTML source:
Homepage: <link rel="canonical" href="undefined/"/>
Finance: <link rel="canonical" href="undefined/specializations/finance"/>

Root Cause: Next.js environment variable for base URL is not being passed correctly during build/runtime. The canonical URL generator is receiving undefined instead of https://www.manpower.co.il.
Fix Required:
// In next.config.js or .env file:
NEXT_PUBLIC_SITE_URL=https://www.manpower.co.il

// Or fix the canonical generation code to use:
const canonicalUrl = process.env.NEXT_PUBLIC_SITE_URL || 'https://www.manpower.co.il';
