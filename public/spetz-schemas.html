להלן דו"ח מסודר הכולל את הבעיות המרכזיות באתר, תוך ציון הליקוי בפועל והמלצה לטיפול.

1. חסרה תגית Meta Description באופן רחב באתר

בעמוד הבית, עמודי ערים ( כולם, למשל אבו גוש, אריאל) עמודי תחומים ראשיים תחת עמוד services, ועמוד צור קשר חסרה תגית Meta Description

בנוסף, בעמודי תתי התחומים, למשל איטום גגות - תגית הדסקריפשיין ארוכה יתר על המידה

המלצה לטיפול:

לבנות תבניות Meta Description קבועות לפי סוג עמוד ולהחיל אותן רוחבית באתר.

2. קובץ robots.txt אינו מוגדר בצורה תקינה

בקובץ robots.txt הנוכחי מופיעה ההגדרה:

User-agent: Googlebots
Allow: /

השם Googlebots אינו תקני (השם הנכון הוא Googlebot), ולכן ההגדרה אינה נכונה. בנוסף, חסרה הפניה למפת האתר (Sitemap), דבר שמקשה על מנועי החיפוש לאתר את כל העמודים החשובים.

המלצה לטיפול:

לעדכן את הקובץ לנוסח הבא:

User-agent: *
Allow: /

Sitemap: https://service.spetz.co.il/sitemap_index.xml

3. היררכיית הכותרות באתר אינה תקינה

בעמוד הבית קיימת תגית H1 בלבד, ללא כותרות משנה מסוג H2 או H3. מצב זה מקשה על מנועי החיפוש להבין את מבנה התוכן ואת הנושאים המרכזיים בעמוד.

בנוסף, בעמודי הערים חסרה תגית H1 תקינה, ונראה כי חסרה גם תגית Canonical.

לדוגמה:

https://service.spetz.co.il/city/%d7%91%d7%99%d7%aa-%d7%90%d7%a8%d7%99%d7%94/

https://service.spetz.co.il/city/%d7%91%d7%99%d7%aa-%d7%93%d7%92%d7%9f/

תגית Canonical חשובה לצורך סימון הכתובת הראשית של העמוד ומסייעת במניעת כפילויות תוכן וגרסאות URL שונות.

מאחר שמדובר בעמודים חשובים לקידום מקומי, יש חשיבות גבוהה למבנה תקין של כותרות ותגיות Canonical.

המלצה לטיפול:

להגדיר H1 אחד בלבד בכל עמוד

להוסיף H2 לנושאים מרכזיים

להוסיף H3 לתתי נושאים

להוסיף H1 ייחודי לכל עמוד עיר

להגדיר תגית Canonical עצמית לכל עמוד עיר

דוגמה ל־Canonical תקין:

<link rel="canonical" href="https://service.spetz.co.il/city/בית-דגן/" />

4. הגדרת הסכמות (Schema) באתר דורשת תיקון

נמצא כי בעמוד הבית מוטמעת סכמה מסוג Article, שאינה מתאימה לעמוד ראשי של אתר שירותים. בנוסף, בחלק גדול מהעמודים חסרות סכמות רלוונטיות כלל.

המלצה לטיפול:

יש להסיר את סכמת Article מעמוד הבית ולהחליפה בסכמות מתאימות.

סוג עמוד כתובת URL Schema מומלצת
עמוד הבית https://service.spetz.co.il/ Organization + WebSite + SearchAction + FAQPage
מרכז ערים https://service.spetz.co.il/מפת-אתר-ערים/ CollectionPage + ItemList + BreadcrumbList
עמוד עיר https://service.spetz.co.il/city/בניה/ CollectionPage + ItemList + BreadcrumbList
מרכז תחומים https://service.spetz.co.il/service/ CollectionPage + ItemList + BreadcrumbList
עמוד תחום https://service.spetz.co.il/service_cat/אינסטלטור/ CollectionPage + ItemList + BreadcrumbList + FAQPage
עמוד שירות עמודי service Service + BreadcrumbList
מאמר עמודי תוכן Article / BlogPosting

דוגמאות סכמה מוכנות ליישום

שימוש: ללחוץ על כפתור "העתק" שליד כל בלוק ולהדביק כתגית <script type="application/ld+json"> בתוך תגית <head>. עמוד הבית מקבל שלושה בלוקים נפרדים (Organization / WebSite+WebPage / FAQPage); שאר העמודים מפנים ל-Organization ול-WebSite דרך @id.

מטריצת סכמות לפי סוג עמוד

סוג עמודסכמות נדרשות
עמוד הביתOrganization (block 1) + WebSite + WebPage (block 2) + FAQPage (block 3)
עמוד עירCollectionPage + ItemList + BreadcrumbList
עמוד תחוםCollectionPage + Service + ItemList + BreadcrumbList + FAQPage

7. עמודי ערים דורשים חיזוק SEO מקומי

המלצה לטיפול:

להוסיף H1 ייחודי עם שם העיר

להרחיב תוכן ייחודי ורלוונטי לכל עיר

להוסיף קישורים פנימיים לשירותים רלוונטיים באותה עיר

להגדיר תגית Canonical עצמית
