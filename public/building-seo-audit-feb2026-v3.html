סה"כ: 6 דפים מרכזיים | השפעה: פגיעה בהיררכיה סמנטית ובדירוג

/ (דף הבית) /about/ (אודות) /building-college/ (בית הספר) /contact/ (צור קשר) /conferences/ (כנסים) /articles/category/קורסים/ (קטגוריית קורסים)

בעיות מטא דאטה

גבוה תיאורי מטא חסרים

סה"כ מוערך: ~80% מהדפים | השפעה: שליטה מופחתת על הצגת התוצאות בגוגל

רוב הדפים שנבדקו לא הכילו תיאור מטא מוגדר. גוגל יוצר תיאור אוטומטי מהתוכן.

מה לתקן:
1. בממשק WordPress, ודא שתוסף Yoast SEO או Rank Math מותקן ומופעל
2. לכל דף, הזן תיאור מטא ייחודי של 150-160 תווים
3. עבור דפי קורסים: כלול שם הקורס, משך, ויתרון עיקרי
4. עבור דפי מפקחים: כלול שם, התמחות, ואזור פעילות

טבלת בעיות מלאה

URL סוג בעיה תיאור הבעיה חומרה עדיפות טיפול מה לתקן
/ H1 חסר H1 קריטי מיידי הוסף תגית H1 עם כותרת הדף הראשית
/ Schema חסר Organization Schema קריטי מיידי הוסף סכמת Organization ל-head
/ Schema חסר WebSite Schema קריטי מיידי הוסף סכמת WebSite ל-head
/about/ H1 חסר H1 קריטי מיידי הוסף תגית H1: "אודות מרכז הבנייה הישראלי"
/building-college/ H1 חסר H1 קריטי מיידי הוסף תגית H1: "בית הספר הגבוה לבינוי ונכסים"
/contact/ H1 חסר H1 קריטי מיידי הוסף תגית H1: "צור קשר"
/conferences/ H1 חסר H1 קריטי מיידי הוסף תגית H1: "כנסים וסמינרים מקצועיים"
/articles/category/קורסים/ H1 חסר H1 גבוה שבוע הוסף תגית H1: "קורסים מקצועיים"
פוטר - כל הדפים Redirect הפניית 301 בקישור לקורס גבוה מיידי עדכן קישור בפוטר ל-URL הסופי
כל דפי האירועים (~40) Schema חסר Event Schema גבוה שבוע הוסף סכמת Event לכל דף אירוע
כל דפי הקורסים (~15) Schema חסר Course Schema גבוה שבוע הוסף סכמת Course לכל דף קורס
כל דפי המפקחים (~68) Schema חסר Person Schema גבוה שבוע הוסף סכמת Person לכל דף מפקח
כל הדפים Schema חסר BreadcrumbList בינוני חודש הוסף BreadcrumbList דינמי לכל דף
כל האתר Images 53% תמונות מעל 100KB גבוה שבוע התקן תוסף אופטימיזציה + WebP
רוב הדפים Meta חסר Meta Description גבוה חודש הוסף תיאורי מטא ייחודיים לכל דף
