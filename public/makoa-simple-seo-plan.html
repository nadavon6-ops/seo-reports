Easy Yoast Cleanup (5 Minutes)

There are some pages that Google shouldn't be looking at — they're internal pages with no value for searchers. Here's how to hide them from Google.

In Yoast SEO > Search Appearance > Taxonomies:
  • Property Amenities → set "Show in search results" to No
  • Property Type → set to No
  • Property State → set to No
  • Property City → set to No
  • Property Flag → set to No
Why: Right now Google is trying to crawl 94 "amenity" pages (one for "microwave", one for "air conditioning", etc.) that all show your homepage content. Hiding them lets Google focus on your real pages instead.
Also hide these individual pages — go to each page in WordPress, scroll to Yoast, click "Advanced", and set "Allow search engines to show this page" to No:
  • /checkout/
  • /confirmation/
  • /guest-dashboard/
  • /search-results/
  • /search-villa/
  • /search-waileainn/
  • /search-penthouse/
These are booking/search pages that don't need to show up on Google.
